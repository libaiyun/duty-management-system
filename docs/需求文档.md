# 广播电视台站值班管理系统 需求说明文档

做一个b/s架构的值班管理系统，支持：

- 添加值机员并简单设置后自动生成排班
- 导出某个月份的值班表
- 支持换班（账号管理、对方同意、领导审批）
- 计算法定节假日加班费退费
- 计算餐补退费
- 支持公休假
- 支持事假、病假
- 顶班人法定节假日退费和餐补退费计算
- 支持微信小程序审批
- 退费方式为微信群自己发红包，支持导出退费表
- 支持导出月度考勤表

### 关于排班

24小时轮班制，分3班：

- 早班：0:00-8:00
- 中班: 8:00-16:00
- 晚班: 16:00-24:00

> 不同台站排班方式不一样，但基本都是24小时3班倒，比如卫星地球站的是每个人上完晚-中-早一轮后休息两天半。

### 关于餐补退费计算

> 这个是扩展功能，目前广发台临时需要。

首先说明餐补：早班10元，中班10元，晚班14元。

餐补按班次每月随工资发放，但是目前广发台实际值班上，中班值机员要上一部分晚班，晚班值机员则负责剩余部分晚班。
餐补里晚班值机员拿到了14元，实际上要退给中班值机员4元。

### 关于法定节假日加班费退费

> 这个是扩展功能，目前广发台临时需要。

首先说明节日加班费：

法定节假日（比如元旦1天、春节3天）当天0-24点，三个班，加班费每个班每人150元。

法定节假日加班费每月随工资发放，但是目前广发台实际值班上，中班值机员要上一部分晚班，晚班值机员则负责剩余部分晚班。
加班费里晚班值机员拿到了150元，实际上要退给中班值机员56元。

### 关于顶班

机房除值机员外，还有上检修班的同志，上行政班。
当值机员请假而非换班时，机房主任安排检修班同志或机房正副主任顶班。
法定节假日值机员不得请假。
