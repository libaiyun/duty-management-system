# M1-P3-T3 开发说明

## Task 范围

本次仅完成 `M1-P3-T3 代码质量工具`。

实施范围：

### 后端

- 新增 `pyproject-flake8` + `flake8` 检查配置（`[tool.flake8]`），最大行宽 120 列。
- 新增 `black` 格式化配置（`[tool.black]`），行宽 120 列。
- 新增 `mypy` 类型检查配置（`mypy.ini`），启用 `disallow_untyped_defs`、`check_untyped_defs`、`warn_return_any`，第三方库设置 `ignore_missing_imports`。
- 新增 `Makefile`：`make lint` / `make format` / `make type-check` / `make test` 统一入口。
- 修复 `mypy` 报告的 3 个类型错误。
- 修复 `flake8` 报告的 10 个 W391（文件尾空行）警告。
- 后端质量命令均通过零错误。

### 前端

- 新增 `eslint` + `typescript-eslint` + `@eslint/js` 开发依赖。
- 新增 `eslint.config.js`（flat config），启用 JS recommended + TS recommended 规则。
- `package.json` 新增 `lint` 脚本：`eslint src/ tests/`。
- 前端质量命令均通过零错误。

### 项目

- `pyproject.toml` 新增 `[project.optional-dependencies] dev` 分组（`black`、`flake8`、`mypy`）。
- `.gitignore` 排除 `mypy` 缓存目录 `.mypy_cache/`。

未实施范围：

- 后端 ruff（需 Python 3.7+，当前环境 Python 3.6 不兼容）。`pflake8` 提供等效能力。
- 前端 prettier 格式化，首期以 `eslint` 检查为主。
- Husky/pre-commit hooks。
- CI 自动执行这些命令，属于 `M1-P3-T4`。

## 可用命令

### 后端

```bash
make lint         # flake8 代码风格检查
make format       # black 代码格式化
make type-check   # mypy 类型检查
make test         # pytest 测试
```

### 前端

```bash
npm run lint      # eslint 代码检查
npm run type-check # vue-tsc 类型检查
npm run test      # vitest 测试
npm run build     # 构建（含 type-check）
```

## 工具配置

### 后端

| 工具 | 配置位置 | 说明 |
|------|----------|------|
| flake8 | `pyproject.toml` `[tool.flake8]` | line-length=120, ignore E203/W503 |
| black | `pyproject.toml` `[tool.black]` | line-length=120, target-version=py38 |
| mypy | `mypy.ini` | strict checks, ignore_missing_imports |
| pytest | `pyproject.toml` `[tool.pytest.ini_options]` | testpaths=backend/tests |

### 前端

| 工具 | 配置位置 | 说明 |
|------|----------|------|
| eslint | `eslint.config.js` | flat config, JS + TS recommended |
| vue-tsc | `tsconfig.json` | strict mode, bundled module resolution |

## 修复清单

| 文件 | 问题 | 修复方式 |
|------|------|----------|
| 10 个 `__init__.py` | W391 文件尾空行 | 清理多余空行 |
| `backend/app/core/config.py` | mypy: StrEnum 参数类型不匹配 | `# type: ignore[arg-type]` |

## 说明

- 后端使用 `pflake8` 命令而非 `flake8`，以读取 `pyproject.toml` 中的配置文件。
- `mypy` 使用独立 `mypy.ini` 配置文件（当前环境 mypy 0.910 不支持 pyproject.toml 配置）。
- `black` 使用 `target-version = py38`（当前环境 black 20.8b0 的最高支持版本）。
- 在 Python 3.11+ 的 Docker 环境中运行时，可升级到新版本 black/ruff/mypy 并支持 pyproject.toml 统一配置。
