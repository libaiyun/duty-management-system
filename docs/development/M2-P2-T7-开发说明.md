## 页面结构

```
班次规则
├─ Tab: 班次定义
│   ├─ [+ 新增班次]
│   └─ 表格: 编码 | 名称 | 时间段 | 顺序 | 状态 | 操作(编辑/停用启用)
│       └─ 弹窗: 编码、名称、开始时间、结束时间、展示顺序
└─ Tab: 排班规则
    ├─ [+ 新增规则]
    └─ 表格: 规则编码 | 名称 | 适用台站类型 | 每班人数 | 适用机房 | 状态 | 操作(编辑/删除)
        └─ 弹窗: 编码、名称、适用台站类型、每班人数、适用机房、状态(编辑时)、备注
            └─ 轮班序列: 班组 + 顺序 + 班次 + 重复次数（可增删行）
```

## API 对接

| 方法 | 路径 | 用途 |
|------|------|------|
| GET | `/api/v1/shifts` | 班次定义列表 |
| POST | `/api/v1/shifts` | 新增班次 |
| PUT | `/api/v1/shifts/{id}` | 编辑班次 / 启停 |
| GET | `/api/v1/shift-rules` | 排班规则列表（含明细） |
| POST | `/api/v1/shift-rules` | 新增规则（含轮班序列） |
| PUT | `/api/v1/shift-rules/{id}` | 编辑规则（明细整体替换） |
| DELETE | `/api/v1/shift-rules/{id}` | 删除规则 |
| GET | `/api/v1/org-units` | 组织列表（适用机房选择/展示） |

## 关键实现

### 枚举值映射

| 类别 | 后端值 → 前端显示 |
|------|------|
| 台站类型 | station_broadcast→广播发射台；station_satellite→卫星地球站 |
| 规则状态 | draft→草稿；enabled→启用；disabled→停用 |
| 班组 | night_early_group→晚早组；middle_group→中班组 |
| 班次码 | early→早班；middle→中班；night→晚班；rest→休息 |

### 轮班序列编辑

排班规则弹窗内以动态行方式编辑 `items`（班组、顺序、班次、重复次数）。新增/编辑保存时整体提交 `items` 数组，与后端 T6 的"传入即整体替换"语义一致；后端会按 `sequence_no` 升序持久化。

### 适用机房

规则表单"适用机房"下拉复用组织数据（type 为 room/station），展示为 `台站名 / 机房名`。不选则规则适用全部（`org_unit_id = null`）。

### 状态字段

规则状态仅在编辑时可改（新增默认后端赋 `draft`），与后端默认值一致。

### 错误提示

创建/编辑/删除失败时通过 `errorMessage` 提取 `ApiError.message` 展示后端返回文案（如编码重复、时间重叠、规则被引用不可删除）；`ElMessageBox` 取消不提示。
