# M1-P2-T1 开发说明

## Task 范围

本次仅完成 `M1-P2-T1 初始化前端工程结构`。

实施范围：

- 新增 `frontend` 前端工程。
- 使用 Vue 3 + TypeScript + Vite。
- 接入 Vue Router。
- 接入 Pinia。
- 预置 Element Plus 依赖，供后续布局和页面 Task 使用。
- 建立基础目录：
  - `src/layouts`
  - `src/router`
  - `src/services`
  - `src/stores`
  - `src/styles`
  - `src/types`
  - `src/views`
  - `tests`
- 提供最小应用入口和占位工作台页面。
- 提供基础 API client 骨架。
- 提供基础样式文件。
- 补充前端单元测试。

未实施范围：

- 完整 Web 后台布局，属于 `M1-P2-T2`。
- API 请求错误处理、Token 注入和分页响应解析，属于 `M1-P2-T3`。
- 动态路由和权限菜单，属于 `M1-P2-T4`。
- 业务页面、表格、表单和审批流程，属于后续业务 Task。

## 运行方式

进入前端目录：

```bash
cd frontend
```

安装依赖：

```bash
npm install
```

启动开发服务：

```bash
npm run dev
```

构建：

```bash
npm run build
```

测试：

```bash
npm run test
```

## 当前测试覆盖

- API client 可以拼接基础 URL 并解析统一响应。
- Router 包含首页路由。
- Pinia store 可以维护基础 shell 状态。

当前 `AppShell` 只提供最小壳层和 `RouterView`，用于验证工程可启动。完整顶部栏、左侧菜单、内容区和面包屑将在 `M1-P2-T2` 中实现。
