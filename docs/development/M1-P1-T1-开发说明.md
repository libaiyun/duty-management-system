# M1-P1-T1 开发说明

## Task 范围

本次仅完成 `M1-P1-T1 初始化后端 FastAPI 工程结构`。

实施范围：

- 初始化后端 FastAPI 应用。
- 提供 `/api/v1/health` 健康检查接口。
- 建立应用基础元数据常量，避免服务名和版本号在代码中重复硬编码。
- 建立后端基础分层目录：
  - `api`
  - `core`
  - `models`
  - `repositories`
  - `schemas`
  - `services`
  - `tests`
- 增加基础单元测试。

未实施范围：

- 环境变量和配置管理，属于 `M1-P1-T2`。
- SQLAlchemy、Alembic 和数据库连接，属于 `M1-P1-T3`。
- 统一响应、分页和异常处理，属于 `M1-P1-T4`。
- 完整测试夹具和测试数据库，属于 `M1-P1-T5`。

## 运行方式

安装依赖：

```bash
python -m pip install -e ".[test]"
```

启动后端：

```bash
uvicorn app.main:app --app-dir backend --reload
```

健康检查：

```bash
curl http://127.0.0.1:8000/api/v1/health
```

预期响应：

```json
{
  "status": "ok",
  "service": "duty-management-system",
  "version": "0.1.0"
}
```

## 测试方式

```bash
pytest
```

当前测试覆盖：

- `create_app()` 返回 FastAPI 应用实例。
- 后端基础分层包可导入。
- 健康检查服务返回固定状态。
- `/api/v1/health` 返回 200 和预期 JSON。
