# M2-P2-T9 开发说明

## Task 范围

本次仅完成 `M2-P2-T9 节假日与标准前端页面`。

实施范围：

- 新增 `views/base-data/HolidayView.vue` — 节假日与标准页面，采用 Tab 结构：
  - **法定节假日 Tab**：年度筛选 + 新增/批量导入工具栏 + 列表（日期、名称、年度、是否法定、状态、备注）+ 编辑/启停/删除操作 + 新增/编辑弹窗 + 批量导入弹窗。
  - **餐补标准 Tab**：只读展示早/中/晚班餐补、餐补退费（固定值）。
  - **节假日加班费标准 Tab**：只读展示加班费、加班费退费（固定值）。
- 更新 `router/index.ts` — `holiday-standard` 路由由 PlaceholderView 改为 HolidayView。

未实施范围：

- 节假日在排班中的标记、请假节假日校验，属于 M3/M4。
- Excel 文件上传导入：批量导入采用文本粘贴方式（每行 `日期,名称[,是否法定]`），Excel 上传属后续优化。

## 页面结构

```
节假日与标准
├─ Tab: 法定节假日
│   ├─ [年度 ▼] [重置]
│   ├─ [+ 新增节假日] [批量导入]
│   └─ 表格: 日期 | 名称 | 年度 | 是否法定 | 状态 | 备注 | 操作(编辑/停用启用/删除)
│       ├─ 新增/编辑弹窗: 日期(编辑禁用)、名称、是否法定、备注
│       └─ 批量导入弹窗: 文本域，每行 日期,名称[,是否法定]
├─ Tab: 餐补标准（只读）
│   └─ 早班餐补 / 中班餐补 / 晚班餐补 / 餐补退费
└─ Tab: 节假日加班费标准（只读）
    └─ 节假日加班费 / 加班费退费
```

## API 对接

| 方法 | 路径 | 用途 |
|------|------|------|
| GET | `/api/v1/holidays?year=` | 节假日列表（可按年度过滤） |
| POST | `/api/v1/holidays` | 新增节假日 |
| POST | `/api/v1/holidays/import` | 批量导入 |
| PUT | `/api/v1/holidays/{id}` | 编辑 / 启停 |
| DELETE | `/api/v1/holidays/{id}` | 删除 |
| GET | `/api/v1/holidays/standard` | 固定补贴/退费标准 |

## 关键实现

### 年度筛选

年度下拉提供「当前年 -2 ~ +3」区间选项，选择后请求 `/holidays?year=`，重置则加载全部。筛选走后端，与 T8 的 `year` 查询参数对接。

### 批量导入

文本域粘贴，每行格式 `日期,名称[,是否法定]`（是否法定省略默认 `1`，即法定）。前端 `parseImportText` 解析为数组后调用 `/holidays/import`，展示后端返回的「新增 N 条，跳过 M 条」。空行与缺少日期/名称的行被跳过。

### 固定标准展示

`GET /holidays/standard` 返回的固定值填充到 `餐补标准` 与 `节假日加班费标准` 两个 Tab，使用 `el-descriptions` 只读展示，并用 `el-alert` 提示「首期固定、暂不支持修改」。

### 日期字段

新增时用 `el-date-picker`（`value-format="YYYY-MM-DD"`）；编辑时日期禁用（后端以日期为唯一键，不允许改期）。

### 错误提示

创建/编辑/删除/导入失败通过 `resolveErrorMessage`（`services/http.ts` 提供的共享工具）提取 `ApiError`/`NetworkError` 的 message 展示后端文案（如日期重复）；`ElMessageBox` 取消操作 return 不提示，取消与真实错误分离处理。
