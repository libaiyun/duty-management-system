## 主要夹具

| 夹具 | 说明 |
| --- | --- |
| `test_settings` | 使用 `test` 环境和临时 SQLite 数据库的应用配置 |
| `app` | 使用 `test_settings` 创建的 FastAPI 应用，并覆盖 `get_db` |
| `api_client` | 默认 `TestClient`，用于普通 API 测试 |
| `api_client_no_raise` | `raise_server_exceptions=False` 的 `TestClient`，用于验证 500 响应 |
| `sqlite_database_url` | 基于 `tmp_path` 的临时 SQLite 数据库地址 |
| `sqlite_engine` | 临时 SQLite engine，测试结束后 dispose |
| `db_session` | 基于同一连接、外层事务和 savepoint 的 SQLAlchemy session，测试结束后 rollback |

## 使用示例

普通 API 测试：

```python
def test_health(api_client):
    response = api_client.get("/api/v1/health")
    assert response.status_code == 200
```

数据库 dependency override 测试：

```python
from fastapi import Depends
from fastapi.testclient import TestClient
from sqlalchemy.orm import Session

from app.db.session import get_db


def test_api_with_db(app):
    @app.get("/example")
    def example(session: Session = Depends(get_db)):
        return {"ok": True}

    with TestClient(app) as client:
        assert client.get("/example").status_code == 200
```

500 异常响应测试：

```python
def test_500(api_client_no_raise):
    response = api_client_no_raise.get("/path-that-raises")
    assert response.status_code == 500
```

## 测试方式

```bash
pytest
```

当前测试覆盖：

- 健康检查可通过统一 `api_client` 测试。
- 异常处理测试可复用测试 settings 和 client。
- `api_client` 挂载的是 `test` 环境配置。
- `get_db` dependency 被覆盖为测试事务 session。
- `db_session` 可写入并查询测试数据。
- `db_session` 支持被测代码内部调用 `commit()`。
