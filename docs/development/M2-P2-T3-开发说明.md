# M2-P2-T3 开发说明

## Task 范围

本次仅完成 `M2-P2-T3 人员模型与 API`。

实施范围：

- 新增 `models/person.py` — `Person` 模型。
- 新增 Alembic 迁移 `m2_p2_t3_person` — 创建 `person` 表。
- 更新 `models/user.py` — `SysUser.person_id` 添加 FK → `person.id`。
- 更新 `models/organization.py` — `OrgUnit.manager_person_id` 添加 FK → `person.id`。
- 新增 `schemas/person.py` — 请求/响应 schema。
- 新增 `api/v1/routes/persons.py` — 4 个 REST 端点。
- 扩展 `services/auth.py` — 新增 `list_persons`、`create_person`、`update_person`。
- 新增 8 个单元测试。

未实施范围：

- 前端人员管理页面，属于 `M2-P2-T4`。
- `person` 与 `sys_user` 的账号绑定 API，属于 `M2-P2-T4`。
- 删除人员的引用校验（换班/请假/排班中有引用时禁止删除），属于 `M3+`。

## 数据模型

### person

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | bigint | PK | 人员 ID |
| org_unit_id | bigint | FK org_unit.id, SET NULL | 所属机房或部门 |
| code | varchar(64) | unique | 人员编号 |
| name | varchar(64) | not null | 姓名 |
| person_type | varchar(32) | not null | duty_operator/maintenance/director/deputy/statistic/admin |
| phone | varchar(32) | nullable | 手机号 |
| participate_schedule | boolean | default false | 是否参与排班 |
| rotation_order | int | nullable | 轮班顺序 |
| status | varchar(32) | default enabled | enabled/disabled |
| remark | varchar(500) | nullable | 备注 |

### 更新的 FK 约束

| 表 | 字段 | FK → | ondelete |
|----|------|------|----------|
| person | org_unit_id | org_unit.id | SET NULL |
| org_unit | manager_person_id | person.id | SET NULL |
| sys_user | person_id | person.id | SET NULL |

## API 端点

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| GET | `/api/v1/persons` | `person:manage:view` | 人员列表 |
| POST | `/api/v1/persons` | `person:manage:view` | 创建人员 |
| GET | `/api/v1/persons/{id}` | `person:manage:view` | 人员详情 |
| PUT | `/api/v1/persons/{id}` | `person:manage:view` | 编辑人员 |
