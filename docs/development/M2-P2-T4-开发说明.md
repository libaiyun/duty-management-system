# M2-P2-T4 开发说明

## Task 范围

本次仅完成 `M2-P2-T4 人员管理前端页面`。

实施范围：

- 新增 `views/base-data/PersonView.vue` — 人员管理前端页面。
  - 查询区：按姓名、人员类型、状态筛选。
  - 工具栏：新增人员按钮。
  - 表格：编号、姓名、人员类型、所属台站机房、手机号、参与排班、轮班顺序、状态、操作。
  - 操作列：编辑、停用/启用、绑定账号（跳转到账号角色页）。
  - 新增/编辑弹窗：人员编号必填（编辑时禁用）、姓名必填、人员类型必填、所属机房可选、手机号可选、参与排班开关、轮班顺序（仅参与排班时显示）、备注。
- 更新 `router/index.ts` — `person` 路由从 PlaceholderView 改为 PersonView。

未实施范围：

- 账号绑定（从人员页直接绑定/创建账号），属于 `M2-P1-T7` 的后续扩展。
- 批量操作（批量导入、批量导出），属于后续优化。
- 组织数据的级联筛选（选择台站后自动过滤机房），属于后续优化。
- 删除人员功能（当前后端未提供删除 API，且人员被业务引用后不应删除）。

## API 对接

| 方法 | 路径 | 用途 |
|------|------|------|
| GET | `/api/v1/persons` | 获取人员列表 |
| POST | `/api/v1/persons` | 新增人员 |
| PUT | `/api/v1/persons/{id}` | 编辑人员 |
| GET | `/api/v1/org-units` | 获取组织列表（用于展示所属台站机房） |

## 关键实现

### 人员类型映射

| 后端值 | 前端显示 |
|--------|---------|
| duty_operator | 值机员 |
| maintenance | 检修班人员 |
| director | 机房主任 |
| deputy | 机房副主任 |
| statistic | 财务/统计人员 |
| admin | 系统管理员 |

### 组织名称显示

人员表格中的「所属台站机房」列通过加载 `/org-units` 全量组织数据，构建 `Map<id, OrgUnit>` 查找表，在渲染时根据 `org_unit_id` 查找到组织名。若组织有父级（机房 → 台站），则显示为 `"台站名 / 机房名"` 格式。

### 状态操作

- 停用/启用：调用 `PUT /persons/{id}` 仅更新 `status` 字段。
- 绑定账号：点击后通过 Router 跳转到 `/system/account-role`，由账号角色页处理账号创建和人员绑定。

### 轮班顺序

「轮班顺序」字段仅在「参与排班」开关打开时显示并允许输入。保存时若未参与排班则 `rotation_order` 传 `null`。

### 前端过滤

姓名搜索、人员类型筛选和状态筛选均为客户端过滤，基于 `computed` 属性实现，不额外请求后端。
