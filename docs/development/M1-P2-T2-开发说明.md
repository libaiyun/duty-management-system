## 布局结构

```text
el-container (app-layout)
  el-header (app-header)
    左侧：折叠按钮 + 系统名称
    右侧：消息通知图标 + 用户下拉菜单
  el-container (app-body)
    el-aside (app-sidebar)
      el-menu (支持折叠)
        一级菜单项：工作台、我的值班、审批中心、排班管理、
                   请假顶班、退费管理、考勤报表、基础资料、系统管理
        二级菜单项：各一级菜单下的子页面
    el-main (app-content)
      el-breadcrumb (面包屑)
      RouterView (页面内容)
```

## 菜单结构

静态菜单基于原型设计文档 `docs/design/02-原型设计.md` 的菜单结构定义：

| 一级菜单 | 二级菜单 |
|----------|----------|
| 工作台 | - |
| 我的值班 | 我的排班、我的换班、我的请假、我的顶班 |
| 审批中心 | 待办审批、已办审批 |
| 排班管理 | 月度排班、排班明细、实际值班 |
| 请假顶班 | 请假记录、顶班安排 |
| 退费管理 | 退费计算、退费明细 |
| 考勤报表 | 月度考勤、导出历史 |
| 基础资料 | 台站机房、人员管理、班次规则、节假日与标准 |
| 系统管理 | 账号角色、操作日志、备份归档 |

当前菜单为静态定义，不按角色过滤。角色权限过滤将在 `M1-P2-T4` 中实现。

## 运行方式

进入前端目录：

```bash
cd frontend
```

安装依赖：

```bash
npm install
```

启动开发服务：

```bash
npm run dev
```

构建：

```bash
npm run build
```

测试：

```bash
npm run test
```

类型检查：

```bash
npm run type-check
```

## 说明

- 用户下拉菜单中「个人设置」和「退出登录」当前为占位，点击无实际功能，将在 `M2-P1` 认证模块中实现。
- 消息通知图标始终显示，计数为 0 时 badge 隐藏。
- 侧边栏菜单通过 `el-menu` 的 `router` 属性启用路由跳转，点击菜单项自动导航到对应页面。
- 所有未实现的页面使用 `PlaceholderView` 占位，显示页面标题和提示文字。
- 面包屑由当前路由 `matched` 记录中携带 `meta.title` 的记录自动生成，路由嵌套结构使面包屑可显示完整层级路径。
- 菜单数据统一维护在 `src/config/menu.ts`，路由由菜单配置自动生成，避免重复定义。
