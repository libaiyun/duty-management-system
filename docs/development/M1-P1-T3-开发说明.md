## 数据库配置

数据库连接地址来自 `DUTY_DATABASE_URL`。

开发默认值：

```text
postgresql+psycopg://duty_app:duty_app@localhost:5432/duty_system
```

生产环境仍由 `M1-P1-T2` 的配置校验保证必须显式设置数据库地址。

## Alembic 使用方式

执行迁移：

```bash
alembic upgrade head
```

生成新迁移：

```bash
alembic revision --autogenerate -m "message"
```

当前首个迁移为空迁移，用于建立迁移链路和 `alembic_version` 表。业务表会在对应业务 Task 中通过独立迁移添加。

## 测试方式

```bash
pytest
```

当前测试覆盖：

- `create_db_engine()` 使用传入配置创建 engine。
- SQLAlchemy 可识别 `postgresql+psycopg` PostgreSQL dialect。
- 测试模型不会污染应用 `Base.metadata`。
- 测试 session 可写入数据。
- 测试事务结束后数据回滚。
- Alembic 可在临时数据库上执行 `upgrade head` 并创建版本表。
