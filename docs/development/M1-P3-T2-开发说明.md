# M1-P3-T2 开发说明

## Task 范围

本次仅完成 `M1-P3-T2 Nginx 反向代理开发配置`。

实施范围：

- 新增 `deploy/nginx/conf.d/default.conf`：Nginx 配置，监听 80 端口。
  - `/` 指向 `frontend/dist` 构建产物（SPA fallback `try_files $uri /index.html`）。
  - `/api/` 反向代理到 `http://backend:8000`，透传 `Host`、`X-Real-IP`、`X-Forwarded-For`、`X-Forwarded-Proto`。
  - `proxy_read_timeout` 120s 避免大报表导出中断。
- 更新 `docker-compose.yml`（基础编排）：
  - 新增 `nginx` 服务：镜像 `nginx:stable`，依赖 `backend` 健康检查。
- 更新 `docker-compose.dev.yml`（开发覆盖）：
  - `nginx` 暴露 80 端口到宿主机。
  - 挂载 `frontend/dist`（只读）和 `deploy/nginx/conf.d`（只读）到 nginx 容器。

未实施范围：

- HTTPS/443 证书配置，属于生产环境（`M6-P3-T5`）。
- 文件下载鉴权（`/files/download/` 不走 nginx 直接映射），属于 `M5-P3`。
- 前端 Vite dev server 代理集成，属于后续 DevEx 优化。

## 服务拓扑

```text
Browser
  -> localhost:80 (nginx)
      -> /            -> frontend/dist (SPA)
      -> /api/*       -> backend:8000
          -> db:5432 (internal)
          -> redis:6379 (internal)
```

## 使用方式

### 首次启动（构建前端后）

```bash
cd frontend && npm run build && cd ..
docker compose -f docker-compose.yml -f docker-compose.dev.yml up -d
docker compose exec backend alembic upgrade head
```

### 日常开发

启动全部服务：

```bash
docker compose -f docker-compose.yml -f docker-compose.dev.yml up -d
```

前端修改后重新构建并生效：

```bash
cd frontend && npm run build
docker compose restart nginx
```

访问地址：

- 前端：`http://localhost`（通过 nginx 80 端口）
- 后端直接：`http://localhost:8000/api/v1/health`

停止服务：

```bash
docker compose down -v
```

## Nginx 配置要点

- `try_files $uri $uri/ /index.html`：支持 Vue SPA 路由，所有非文件路径回退到 `index.html`。
- `proxy_pass http://backend:8000`（不带尾斜杠）：完整路径透传，`/api/v1/health` -> `http://backend:8000/api/v1/health`。
- `proxy_read_timeout 120s`：足够长以支持未来大报表导出下载。
- 配置文件挂载为只读（`:ro`），生产环境同理。

## 说明

- 前端构建产物 `frontend/dist` 由 `npm run build` 生成，未提交到 Git 仓库（已在 `.gitignore` 中）。
- Nginx 配置通过只读卷挂载，修改后需 `docker compose restart nginx` 生效。
- 后续可通过 `docker-compose.prod.yml` 覆盖 nginx 配置以启用 HTTPS、域名、证书等生产特性。
