## 代码变更

### 1. `backend/app/services/schedule.py` — 重写

新增 `generate_schedule_from_rule` 函数：

```python
def generate_schedule_from_rule(
    db: Session,
    rule: ShiftRule,
    version: ShiftRuleVersion,
    *,
    total_days: int = 365,
) -> int:
```

**改进点**：

| 项目 | 旧实现（auth.py） | 新实现（schedule.py） |
|------|------------------|----------------------|
| 位置 | `auth.py`（职责错乱） | `schedule.py`（排班服务层） |
| 模型导入 | 函数体内 `from ... import ... as _MS` | 模块级 `from app.models.schedule import ...` |
| 类型安全 | 7 处 `type: ignore[arg-type]` | 0 处（直接使用标准类型） |
| 节假日 | 无（`is_legal_holiday=False`） | 批量查 `HolidayCalendar`，设置 `is_legal_holiday` + `holiday_name` |
| 日期范围 | `max(sd, tomorrow) + timedelta(days=365)` | 相同逻辑，新增 `total_days` 参数默认 365 |

新增 `_load_holidays` 私有函数：批量加载日期范围内的法定节假日，避免逐日查询。

### 2. `backend/app/services/auth.py` — 删除 + 调用更新

- **删除**：`_generate_schedule_from_rule` 函数体（~105 行）
- **修改**：`publish_shift_rule` 末尾调用改为 `from app.services.schedule import generate_schedule_from_rule`

### 3. `backend/tests/test_shift_rules.py` — 新增 4 个测试

| 测试用例 | 场景 | 验证点 |
|---------|------|--------|
| `test_multi_cycle_repeats_pattern` | N=3 天循环 10 天 | Day 4 与 Day 1 人员相同（周期重复） |
| `test_cross_month_continuity` | 7月30日起生成 6 天 | 7/30, 7/31, 8/1, 8/2, 8/3, 8/4 全部存在 |
| `test_holiday_flagging` | 10月1-2日为国庆节 | `is_legal_holiday=True`, `holiday_name="国庆节"`；10/3 为 `False` |
| `test_republish_overwrites_future` | 先发布 v1，再发布 v2（Day 2 人员变更） | v2 发布后 Day 2 人员为 v2 配置 |

## 节假日集成

```
生成排班日期列表 → 批量查询 HolidayCalendar
  → {date: holiday_name} 映射
    → ScheduleDay.is_legal_holiday = True/False
    → ScheduleDay.holiday_name = "国庆节" / None
```

查询条件：`is_legal=True` + `status="enabled"` + 日期在生成范围内。
