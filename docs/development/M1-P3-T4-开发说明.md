# M1-P3-T4 开发说明

## Task 范围

本次仅完成 `M1-P3-T4 基础 CI 脚本`。

实施范围：

- 新增 `check.sh`：统一 CI 检查脚本，覆盖后端和前端全部质量门禁。
  - 后端（通过 Docker Compose）：lint → type-check → test
  - 前端（本地）：lint → type-check → build
  - 任一检查失败时 `exit 1` 停止后续步骤。
- 扩展 `Makefile`：新增 `check` 目标，调用 `check.sh`。
- 新增 `setup.cfg`：`flake8` 配置文件（兼容本地和 Docker 环境）。
- 更新 `Dockerfile`：安装 `.[test,dev]` 依赖以包含 CI 工具。
- 修复 4 个 Docker 环境下 `mypy` 新增的类型错误。

未实施范围：

- GitHub Actions / GitLab CI 等外部 CI 平台的配置 YAML，属于后续部署阶段。
- 代码覆盖率统计和质量门禁阈值。
- 性能基准测试和回归检测。

## 检查清单

`check.sh` 按序执行以下检查：

| # | 检查项 | 方式 | 工具 |
|---|--------|------|------|
| 1 | 后端 lint | Docker | `flake8 backend/app` |
| 2 | 后端 type-check | Docker | `mypy` |
| 3 | 后端 test | Docker | `pytest` |
| 4 | 前端 lint | 本地 | `eslint src/ tests/` |
| 5 | 前端 type-check | 本地 | `vue-tsc --noEmit` |
| 6 | 前端 build | 本地 | `vite build` |

## 使用方式

### 一键检查

```bash
bash check.sh
```

或通过 Makefile：

```bash
make check
```

### 单独检查

```bash
make lint         # 后端代码风格
make type-check   # 后端类型检查
make test         # 后端测试

cd frontend
npm run lint      # 前端代码风格
npm run type-check # 前端类型检查
npm run build     # 前端构建
```

## 说明

- 后端检查通过 Docker Compose 运行，确保使用与生产一致的 Python 3.13 + 依赖环境。
- 前端检查在本地执行，复用已安装的 `node_modules`。
- `check.sh` 在检查完成后自动执行 `docker compose down -v` 清理容器和卷。
- 后端使用 `setup.cfg` 配置 `flake8`（兼容本地 Python 3.6 和 Docker Python 3.13）。
- `Dockerfile` 已更新为安装 `.[test,dev]`，镜像中包含 pytest、flake8、black、mypy 等开发工具。
