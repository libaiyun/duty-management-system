# M1-P1-T2 开发说明

## Task 范围

本次仅完成 `M1-P1-T2 配置与环境变量管理`。

实施范围：

- 新增 `app.core.config` 配置模块。
- 支持 `dev`、`test`、`prod` 三类运行环境。
- 支持从环境变量读取数据库、Redis、JWT 和文件目录配置。
- 开发/测试环境提供默认值，方便本地启动和单元测试。
- 生产环境要求显式提供关键配置，缺失时抛出明确 `ConfigError`。
- 生产环境禁止使用 `change-me` 或 `dev-only-change-me` 作为 JWT 密钥。
- FastAPI 应用启动时将配置挂载到 `app.state.settings`。
- 新增 `.env.example` 作为环境变量模板。

未实施范围：

- 数据库连接和迁移，属于 `M1-P1-T3`。
- JWT 登录签发和认证校验，属于 `M2-P1`。
- 统一异常响应格式，属于 `M1-P1-T4`。
- Docker Compose 环境注入，属于 `M1-P3`。

## 环境变量

| 变量 | 说明 | 默认值 |
| --- | --- | --- |
| `DUTY_APP_ENV` | 运行环境，可选 `dev`、`test`、`prod` | `dev` |
| `DUTY_DATABASE_URL` | PostgreSQL 连接地址 | 本地开发库地址 |
| `DUTY_REDIS_URL` | Redis 连接地址 | `redis://localhost:6379/0` |
| `DUTY_JWT_SECRET_KEY` | JWT 签名密钥 | `dev-only-change-me` |
| `DUTY_JWT_ALGORITHM` | JWT 签名算法 | `HS256` |
| `DUTY_JWT_ACCESS_TOKEN_EXPIRE_MINUTES` | Access Token 有效分钟数 | `30` |
| `DUTY_JWT_REFRESH_TOKEN_EXPIRE_MINUTES` | Refresh Token 有效分钟数 | `10080` |
| `DUTY_FILE_STORAGE_DIR` | 文件存储根目录 | `data/files` |
| `DUTY_EXPORT_DIR` | 导出文件目录 | `data/files/export` |
| `DUTY_BACKUP_DIR` | 备份文件目录 | `data/files/backup` |

生产环境 `DUTY_APP_ENV=prod` 时，必须显式配置：

- `DUTY_DATABASE_URL`
- `DUTY_REDIS_URL`
- `DUTY_JWT_SECRET_KEY`
- `DUTY_FILE_STORAGE_DIR`
- `DUTY_EXPORT_DIR`
- `DUTY_BACKUP_DIR`

其中 `DUTY_JWT_SECRET_KEY` 必须替换为生产密钥，不能使用 `.env.example` 中的占位值。

## 使用方式

加载当前环境配置：

```python
from app.core.config import load_settings

settings = load_settings()
```

传入显式配置创建应用，主要用于测试：

```python
from app.main import create_app

app = create_app(settings=settings)
```

应用内可通过 `app.state.settings` 获取配置。

## 测试方式

```bash
pytest
```

当前测试覆盖：

- 默认开发环境配置。
- 环境变量覆盖。
- 非法运行环境。
- 非法正整数配置。
- 生产环境缺失关键变量时报错。
- 生产环境使用占位 JWT 密钥时报错。
- FastAPI 应用挂载配置到 `app.state.settings`。
