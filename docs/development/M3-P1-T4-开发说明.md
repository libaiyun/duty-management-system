## API 端点

### `POST /api/v1/schedules/{id}/generate`

**权限**：`schedule:monthly:view`

**说明**：对已有排班执行生成/刷新，调用 `generate_schedule_from_rule` 从关联规则的已发布版本生成排班日数据。

**请求**：路径参数 `id`（排班 ID），无请求体。

**响应**：`ScheduleResponse`（含 `day_count` / `shift_count` / `person_count` 统计）。

**处理流程**：

```
排班 ID → 查找 MonthlySchedule
  → 查找关联 ShiftRule → 检查 status == "published"
    → 查找最新已发布 ShiftRuleVersion
      → generate_schedule_from_rule(db, rule, version)
        → 刷新 MonthlySchedule → 返回 ScheduleResponse
```

**错误码**：

| 场景 | HTTP | code |
|------|------|------|
| 排班不存在 | 404 | NOT_FOUND |
| 关联规则未发布 | 422 | BUSINESS_RULE_FAILED |
| 规则无已发布版本 | 422 | BUSINESS_RULE_FAILED |
| 无权限 | 403 | FORBIDDEN |

## 排班刷新行为

生成/刷新逻辑由 `generate_schedule_from_rule` 实现（`schedule.py`），与规则发布调用的入口相同：

- **首次生成**：从 `start_date` 起创建全部排班日数据（默认 365 天）
- **重新生成**：今天之前的日期保留不动（skip），今天起删除旧数据再重新创建
- **节假日**：自动从 `HolidayCalendar` 表加载并标记 `is_legal_holiday` 和 `holiday_name`
