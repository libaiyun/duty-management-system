## 页面功能

### 筛选区

| 控件 | 类型 | 说明 |
|------|------|------|
| 机房 | el-select | 从 org-units 加载 type=room 的机房，选择后触发查询 |
| 月份 | el-date-picker (month) | 默认当前月份，用于展示和跳转明细 |
| 状态 | el-select | draft / published / locked |
| 重置 | el-button | 清空筛选条件，恢复默认月份 |

### 排班列表表格

| 列 | 宽度 | 说明 |
|----|------|------|
| 月份 | 120px | 当前选中的月份（YYYY年M月） |
| 机房 | min-180px | 台站 / 机房 层级显示 |
| 排班规则 | min-140px | 关联的规则名称 |
| 班次数 | 80px | 排班中的班次总数 |
| 人员数 | 80px | 排班中的值班人员总数 |
| 状态 | 90px | 草稿/已发布/已锁定，颜色标签 |
| 更新时间 | 170px | 生成时间，格式化显示 |
| 操作 | 140px | "查看明细"按钮 |

### 异常提示

| 场景 | 提示文案 |
|------|---------|
| 未选机房 | "请选择机房查看排班，或前往排班规则页配置规则" |
| 已选机房但无数据 | "该机房暂无排班数据，请先在排班规则页配置并发布规则" |
| 筛选草稿无结果 | "没有草稿状态的排班" |

## 数据流

```
onMounted:
  loadOrgUnits() → GET /org-units → orgUnits[]
  loadSchedules() → GET /schedules?org_unit_id=&status= → schedules[]

用户操作:
  选机房 → loadSchedules()
  选状态 → loadSchedules()
  选月份 → 仅更新 displayMonth
  查看明细 → router.push({ name: 'schedule-detail', query: { scheduleId, year, month } })
```
