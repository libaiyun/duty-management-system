## 核心实现

### `DataScope` 类型

```python
@dataclass(frozen=True)
class DataScope:
    scope_type: str       # self / room / station / all
    org_unit_id: int | None = None  # 组织 ID（room/station 时使用）
```

四种范围类型：

| scope_type | 含义 | org_unit_id |
|-----------|------|-------------|
| `self` | 仅本人数据 | `None` |
| `room` | 指定机房内数据 | 机房 org_unit_id |
| `station` | 指定台站下所有机房数据 | 台站 org_unit_id |
| `all` | 全局数据 | `None` |

### `resolve_user_data_scopes(db, user) -> list[DataScope]`

解析用户的有效数据范围，来源包括：

1. **直接分配** — `sys_data_scope` 中 `user_id = user.id` 的记录
2. **角色继承** — 用户所拥有的角色关联的 `sys_data_scope` 记录（`role_id` 匹配）

返回去重后的 `DataScope` 列表。相同 `(scope_type, org_unit_id)` 组合只保留一条。

```python
def resolve_user_data_scopes(db: Session, user: SysUser) -> list[DataScope]:
    role_ids = db.scalars(
        select(sys_user_role.c.role_id).where(sys_user_role.c.user_id == user.id)
    ).all()

    stmt = select(SysDataScope).where(
        (SysDataScope.user_id == user.id)
        | (SysDataScope.role_id.in_(role_ids) if role_ids else False)
    )

    seen: set[tuple[str, int | None]] = set()
    result: list[DataScope] = []
    for scope in db.scalars(stmt):
        key = (scope.scope_type, scope.org_unit_id)
        if key not in seen:
            seen.add(key)
            result.append(DataScope(scope.scope_type, scope.org_unit_id))

    return result
```

### `has_global_scope(scopes) -> bool`

判断解析后的范围列表中是否包含 `all` 类型。`all` 表示不受任何组织范围限制。

## 使用方式

业务模块调用示例（后续 `M2-P2` 实现）：

```python
from app.services.auth import resolve_user_data_scopes, has_global_scope

def list_schedules(db, user, month):
    scopes = resolve_user_data_scopes(db, user)
    if has_global_scope(scopes):
        return query_all_schedules(db, month)

    query = select(Schedule).where(Schedule.year_month == month)
    org_filters = []
    for scope in scopes:
        if scope.scope_type == "self":
            org_filters.append(Schedule.person_id == user.person_id)
        elif scope.scope_type in ("room", "station") and scope.org_unit_id:
            org_filters.append(Schedule.org_unit_id == scope.org_unit_id)
    if org_filters:
        query = query.where(or_(*org_filters))
    return db.scalars(query).all()
```

## 说明

- 数据范围模型已在 `M2-P1-T1` 中建立（`sys_data_scope` 表），本次仅新增查询服务。
- `org_unit_id` 字段当前无 FK 约束（`org_unit` 表属于 `M2-P2`），解析后的值由业务模块自行 JOIN。
- 当用户直接和角色均有 `all` 范围时，去重后只保留一条 `DataScope("all")`。
- `resolve_user_data_scopes` 不区分 scope_type 的优先级——`all` 和 `self` 可同时返回，由调用方自行选择过滤策略。
- `has_global_scope` 为便利函数，调用方可用于短路判断是否需要组织范围 JOIN。
