## 数据模型

### holiday_calendar

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | bigint | PK | 节假日 ID |
| holiday_date | date | unique | 日期 |
| holiday_name | varchar(64) | not null | 名称 |
| year | int | not null（索引） | 年度，由 holiday_date 自动派生 |
| is_legal | boolean | default true | 是否法定节假日 |
| status | varchar(32) | default 'enabled' | enabled/disabled |
| remark | varchar(255) | nullable | 备注 |

`holiday_date` 唯一约束 `uq_holiday_calendar_date`；`year` 建立索引 `ix_holiday_calendar_year`。

## API 端点

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| GET | `/api/v1/holidays?year=` | 查询节假日列表（按日期排序，可按年度过滤） | `holiday:standard:view` |
| GET | `/api/v1/holidays/standard` | 查询固定补贴/退费标准（只读） | `holiday:standard:view` |
| POST | `/api/v1/holidays` | 新增节假日（日期唯一校验） | `holiday:standard:view` |
| POST | `/api/v1/holidays/import` | 批量导入（已存在/重复日期跳过） | `holiday:standard:view` |
| GET | `/api/v1/holidays/{id}` | 查询详情 | `holiday:standard:view` |
| PUT | `/api/v1/holidays/{id}` | 编辑（名称、是否法定、状态、备注） | `holiday:standard:view` |
| DELETE | `/api/v1/holidays/{id}` | 删除 | `holiday:standard:view` |

权限码沿用已 seed 的 `holiday:standard:view`（`cli.py`），本 Task 不新增权限码。

> 路由顺序说明：`/standard` 与 `/import` 静态路径注册在 `/{holiday_id}` 之前，避免被路径参数吞掉。

## 业务校验

- **日期唯一性**：同一 `holiday_date` 重复创建返回 409 `STATE_CONFLICT`。
- **year 自动派生**：`year` 由 `holiday_date.year` 计算，不接受客户端传入，避免不一致。
- **批量导入去重**：导入时跳过数据库已存在日期与本批次内重复日期，返回 `created`/`skipped`/`skipped_dates`，不因单条冲突整批失败。
- **固定标准只读**：`GET /standard` 返回总体设计 §12.2 固定值（早/中/晚餐补 10/10/14、餐补退费 4、加班费 150、加班费退费 56），首期不可改。
