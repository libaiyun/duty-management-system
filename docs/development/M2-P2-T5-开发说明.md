## 数据模型

### shift_def

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | bigint | PK | 班次 ID |
| code | varchar(64) | unique | 编码，如 early/middle/night |
| name | varchar(64) | not null | 名称，如 早班/中班/晚班 |
| start_time | varchar(5) | not null | 开始时间 HH:MM |
| end_time | varchar(5) | not null | 结束时间 HH:MM |
| display_order | int | default 0 | 展示顺序 |
| status | varchar(32) | default 'enabled' | enabled/disabled |

## API 端点

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| GET | `/api/v1/shifts` | 查询班次列表（按 display_order 排序） | `shift:rule:view` |
| POST | `/api/v1/shifts` | 新增班次（含编码唯一性校验、时间重叠校验） | `shift:rule:view` |
| GET | `/api/v1/shifts/{id}` | 查询班次详情 | `shift:rule:view` |
| PUT | `/api/v1/shifts/{id}` | 编辑班次（名称、时间、顺序、状态） | `shift:rule:view` |

## 业务校验

### 编码唯一性
班次编码（`code`）唯一，重复创建返回 409 `STATE_CONFLICT`。

### 时间重叠校验
新班次的时间段与已启用的班次时间段重叠时，返回 422 `BUSINESS_RULE_FAILED`。
校验算法为 `start_a < end_b AND start_b < end_a`，基于分钟数比较，不支持跨午夜场景。
