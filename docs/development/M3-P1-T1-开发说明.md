## 数据模型

### monthly_schedule

排班主表，每个机房一条记录。排班从起始日期起循环写入 365 天，展示和导出按月切片。

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | bigint | PK, autoincrement | 排班 ID |
| org_unit_id | bigint | FK org_unit.id ON DELETE RESTRICT, NOT NULL | 机房 |
| rule_id | bigint | FK shift_rule.id ON DELETE RESTRICT, NOT NULL | 规则 |
| rule_version_id | bigint | FK shift_rule_version.id ON DELETE RESTRICT, NOT NULL | 规则版本 |
| status | varchar(32) | NOT NULL, default 'draft' | draft/published/locked |
| generated_at | timestamptz | nullable | 生成时间 |
| published_at | timestamptz | nullable | 发布时间 |
| locked_at | timestamptz | nullable | 锁定时间 |
| remark | varchar(500) | nullable | 备注 |

唯一约束：`uq_monthly_schedule_org(org_unit_id) WHERE deleted_at IS NULL`

说明：去除 `year_month` 字段，不再以月度为单位。前端按月选择时，按 `schedule_day.duty_date` 范围过滤。

### schedule_day

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | bigint | PK, autoincrement | 日期 ID |
| schedule_id | bigint | FK monthly_schedule.id ON DELETE CASCADE, NOT NULL | 所属排班 |
| duty_date | date | NOT NULL | 日期 |
| weekday | int | NOT NULL | 星期 (0=Mon..6=Sun) |
| is_legal_holiday | boolean | NOT NULL, default false | 是否法定节假日 |
| holiday_name | varchar(64) | nullable | 节假日名称 |

索引：`ix_schedule_day_duty_date(duty_date)`

### schedule_shift

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | bigint | PK, autoincrement | 班次排班 ID |
| schedule_day_id | bigint | FK schedule_day.id ON DELETE CASCADE, NOT NULL | 日期 |
| shift_def_id | bigint | FK shift_def.id ON DELETE RESTRICT, NOT NULL | 班次定义 |
| start_at | timestamptz | NOT NULL | 班次开始 |
| end_at | timestamptz | NOT NULL | 班次结束 |
| status | varchar(32) | NOT NULL, default 'normal' | normal/changed/locked |

索引：`ix_schedule_shift_day(schedule_day_id)`

### schedule_shift_person

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | bigint | PK, autoincrement | 人员 ID |
| schedule_shift_id | bigint | FK schedule_shift.id ON DELETE CASCADE, NOT NULL | 班次排班 |
| person_id | bigint | FK person.id ON DELETE RESTRICT, NOT NULL | 原排班人员 |
| position_no | int | NOT NULL, default 1 | 岗位序号 |
| source_type | varchar(32) | NOT NULL, default 'auto' | auto/manual |
| remark | varchar(255) | nullable | 调整说明 |

索引：`ix_schedule_shift_person_shift(schedule_shift_id)`

### 级联关系

```
monthly_schedule [CASCADE]
  └── schedule_day [CASCADE]
        └── schedule_shift [CASCADE]
              └── schedule_shift_person
```

引用表（Person、ShiftDef）使用 RESTRICT，防止误删。
