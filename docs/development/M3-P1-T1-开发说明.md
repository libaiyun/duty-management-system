## 数据模型

### monthly_schedule（月度排班主表）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | bigint | PK | 月度排班 ID |
| org_unit_id | bigint | FK org_unit.id (RESTRICT) | 机房 ID |
| year_month | varchar(7) | not null | yyyy-MM |
| rule_id | bigint | FK shift_rule.id (RESTRICT) | 使用规则 |
| status | varchar(32) | not null, default 'not_generated' | not_generated/draft/published/adjusted/locked/cancelled |
| generated_at | timestamptz | nullable | 生成时间 |
| published_at | timestamptz | nullable | 发布时间 |
| locked_at | timestamptz | nullable | 锁定时间 |
| remark | varchar(500) | nullable | 备注 |

唯一约束：**部分唯一索引** `uq_monthly_schedule_org_month(org_unit_id, year_month) WHERE deleted_at IS NULL`。
设计意图：禁止同一机房同月存在多份活跃排班，但软删除后可创建新排班。

### schedule_day（排班日期）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | bigint | PK | 日期 ID |
| schedule_id | bigint | FK monthly_schedule.id (CASCADE) | 月度排班 ID |
| duty_date | date | not null | 日期 |
| weekday | int | not null | 星期（0=周一...6=周日，Python 惯例） |
| is_legal_holiday | boolean | not null, default false | 是否法定节假日 |
| holiday_name | varchar(64) | nullable | 节假日名称 |

索引：`ix_schedule_day_duty_date`、`ix_schedule_day_schedule_id`。

### schedule_shift（班次排班）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | bigint | PK | 班次排班 ID |
| schedule_day_id | bigint | FK schedule_day.id (CASCADE) | 日期 ID |
| shift_def_id | bigint | FK shift_def.id (RESTRICT) | 班次定义 |
| start_at | timestamptz | not null | 班次开始 |
| end_at | timestamptz | not null | 班次结束 |
| status | varchar(32) | not null, default 'normal' | normal/changed/locked |

索引：`ix_schedule_shift_day`。

### schedule_shift_person（排班人员）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | bigint | PK | 排班人员 ID |
| schedule_shift_id | bigint | FK schedule_shift.id (CASCADE) | 班次排班 ID |
| person_id | bigint | FK person.id (RESTRICT) | 原排班人员 |
| position_no | int | not null, default 1 | 岗位序号 |
| source_type | varchar(32) | not null, default 'auto' | auto/manual |
| remark | varchar(255) | nullable | 说明 |

索引：`ix_schedule_shift_person_shift`。

### 级联关系

```text
MonthlySchedule (RESTRICT on org_unit, rule)
  └─CASCADE→ ScheduleDay
                └─CASCADE→ ScheduleShift (RESTRICT on shift_def)
                              └─CASCADE→ ScheduleShiftPerson (RESTRICT on person)
```

级联规则：
- 删除排班 → 自动删除所有日期、班次、人员分配。
- 删除日期 → 自动删除该日所有班次和人员。
- `org_unit`、`shift_rule`、`shift_def`、`person` 被引用时禁止删除（RESTRICT）。

## 验证方式

```bash

docker compose -f docker-compose.yml -f docker-compose.dev.yml run --rm --no-deps backend ruff check backend/app
docker compose -f docker-compose.yml -f docker-compose.dev.yml run --rm --no-deps backend mypy

# 单元测试
docker compose -f docker-compose.yml -f docker-compose.dev.yml run --rm --no-deps backend pytest

# 迁移验证
docker compose -f docker-compose.yml -f docker-compose.dev.yml run --rm --no-deps backend alembic downgrade -1
docker compose -f docker-compose.yml -f docker-compose.dev.yml run --rm --no-deps backend alembic upgrade heads
```

验证结果：
- ruff: All checks passed
- mypy: 0 issues, 51 source files
- pytest: 196 passed (22 new + 174 existing)
- 迁移 upgrade/downgrade/upgrade 均成功
