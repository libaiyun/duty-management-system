# M2-P1-T7 开发说明

## Task 范围

本次仅完成 `M2-P1-T7 账号角色管理页面与 API`。

实施范围：

### 后端

- 新增 `schemas/user.py` — 用户 CRUD 请求/响应 schema。
- 新增 `schemas/role.py` — 角色 CRUD 请求/响应 schema。
- 新增 `api/v1/routes/users.py` — 用户列表/创建/查询/编辑/角色分配/数据范围设置 API。
- 新增 `api/v1/routes/roles.py` — 角色列表/创建/查询/编辑/权限分配 API。
- 新增 `api/v1/routes/permissions.py` — 权限列表 API。
- 扩展 `services/auth.py` — 新增 `list_users`/`update_user`/`assign_user_roles`/`assign_user_data_scopes`/`list_roles`/`create_role`/`update_role`/`assign_role_permissions`/`list_permissions`。
- 新增 9 个后端单元测试。

### 前端

- 新增 `views/system/AccountRoleView.vue` — 账号角色管理页面（Tab：账号管理/角色管理）。
- 更新 `router/index.ts` — `account-role` 路由使用专用组件，新增 `CUSTOM_VIEWS` 映射支持懒加载。

未实施范围：

- `person_id` 字段绑定（`person` 表属于 `M2-P2`），当前仅保留字段并展示。
- 数据范围 `org_unit_id` 的实际组织树选择（`org_unit` 表属于 `M2-P2`）。
- 用户列表分页（当前全量返回，后续按需加 pagination）。
- 批量操作（批量启停、批量分配角色）。

## 说明

- 所有管理端点均受 `system:user:manage` 权限保护，使用 `RequirePermission` 依赖。
- 用户创建时密码通过 bcrypt 哈希存储（复用 `M2-P1-T2` 的 `create_user`）。
- 数据范围 `assign_user_data_scopes` 采用"先删后增"策略，确保幂等。
- 角色分配 `assign_user_roles` 和权限分配 `assign_role_permissions` 直接替换关联集合。
- 前端页面使用 Tab 切换，账号管理和角色管理共享同一组件，通过惰性加载 dialog 减少初始渲染。
- 前端 `CUSTOM_VIEWS` 路由映射支持后续 Task 逐步替换 PlaceholderView，无需再修改路由逻辑。
