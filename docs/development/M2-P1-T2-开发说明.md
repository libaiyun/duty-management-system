# M2-P1-T2 开发说明

## Task 范围

本次仅完成 `M2-P1-T2 登录与 Token 刷新 API`。

实施范围：

- 新增 `app.core.security` 安全模块：
  - `hash_password` / `verify_password`：基于 `bcrypt` 的密码哈希与验证。
  - `create_access_token` / `create_refresh_token`：基于 `python-jose` 的 JWT 签发。
  - `decode_token`：JWT 解码与过期校验。
  - `get_current_user`：从 `Authorization: Bearer <token>` 中提取当前用户，校验 token 类型和用户状态。
- 新增 `app.services.auth` 认证服务：
  - `authenticate_user`：用户名密码验证，校验状态（enabled/locked）。
  - `create_user`：创建用户（测试用，后续 M2-P1-T7 中扩展）。
  - `issue_tokens`：签发 access + refresh token 对。
  - `refresh_access_token`：使用 refresh token 刷新 access token。
- 新增 `app.schemas.auth`：`LoginRequest`、`TokenResponse`、`RefreshRequest`、`UserMeResponse` Pydantic 请求/响应模型。
- 新增 `app.api.v1.routes.auth` 认证路由：
  - `POST /api/v1/auth/login`：用户名密码登录，返回 access/refresh token。
  - `POST /api/v1/auth/refresh`：刷新 access token（需 refresh token）。
  - `POST /api/v1/auth/logout`：退出登录（当前为客户端丢弃 token，后续 M6 对接 Redis 黑名单）。
  - `GET /api/v1/auth/me`：获取当前登录用户信息（需 access token）。
- 更新 `app.api.v1.router`：注册 auth 路由。
- 更新 `app.api.deps`：重新导出 `get_db` 供路由依赖。
- 更新 `pyproject.toml`：新增 `bcrypt` 和 `python-jose[cryptography]` 依赖。
- 更新 `backend/tests/conftest.py`：新增 `create_tables` fixture。
- 新增 `backend/tests/test_auth.py`：11 个认证 API 测试。

未实施范围：

- 密码策略（强度、加密方式切换），属于 `M2-P1-T3`。
- 账号创建 API 和管理页面，属于 `M2-P1-T7`。
- Token 黑名单和强制下线，属于 `M6`（依赖 Redis）。
- 角色/权限数据注入 `/auth/me` 响应，属于 `M2-P1-T4`。
- 微信 OAuth 登录绑定，属于后续扩展。

## API 详情

### POST /api/v1/auth/login

```json
// Request
{ "username": "admin", "password": "password123" }

// Response 200
{
  "code": "OK",
  "data": {
    "access_token": "eyJ...",
    "refresh_token": "eyJ...",
    "token_type": "bearer"
  }
}

// Response 401 — 账号不存在、密码错误、已锁定/停用
{ "code": "UNAUTHORIZED", "message": "账号或密码错误" }

// Response 400 — 空用户名
{ "code": "VALIDATION_ERROR", "message": "参数校验失败" }
```

### POST /api/v1/auth/refresh

```json
// Request
{ "refresh_token": "eyJ..." }

// Response 200
{ "code": "OK", "data": { "access_token": "...", "refresh_token": "..." } }

// Response 401 — token 无效、过期、类型非 refresh
{ "code": "UNAUTHORIZED", "message": "登录已过期，请重新登录" }
```

### GET /api/v1/auth/me

```
Header: Authorization: Bearer <access_token>

Response 200
{
  "code": "OK",
  "data": {
    "id": 1,
    "username": "admin",
    "display_name": "管理员",
    "status": "enabled"
  }
}

Response 401 — 缺少 token、token 无效、用户不存在/已停用
```

### POST /api/v1/auth/logout

```
Response 200
{ "code": "OK", "message": "已退出登录" }
```

## Token 结构

### Access Token

```json
{
  "sub": "1",
  "username": "admin",
  "type": "access",
  "exp": 1752123456
}
```

- 有效期：30 分钟（`DUTY_JWT_ACCESS_TOKEN_EXPIRE_MINUTES`）
- 签名：HS256（`DUTY_JWT_ALGORITHM`）

### Refresh Token

```json
{
  "sub": "1",
  "username": "admin",
  "type": "refresh",
  "exp": 1752728256
}
```

- 有效期：7 天（`DUTY_JWT_REFRESH_TOKEN_EXPIRE_MINUTES`）

## 说明

- 密码使用 `bcrypt` 哈希存储，每个密码独立 `gensalt()`。
- `python-jose[cryptography]` 提供 JWT 编码/解码能力（HS256 算法）。
- `decode_token` 在 token 过期或签名无效时抛出 `UnauthorizedError`（401）。
- `get_current_user` 额外校验 token type 为 `"access"`、用户存在且 `status == "enabled"`。
- 登录成功时更新 `last_login_at` 字段。
- 测试使用 SQLite 内存数据库，自动创建表（`create_tables` fixture）。
