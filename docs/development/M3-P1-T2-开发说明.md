## API 端点

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| GET | `/api/v1/schedules` | `schedule:monthly:view` | 分页查询月度排班列表，支持 `org_unit_id` / `year_month` / `status` 查询参数 |
| GET | `/api/v1/schedules/{id}` | `schedule:monthly:view` | 排班详情，含 org_unit/rule 关联信息和 day_count/shift_count/person_count 汇总 |
| GET | `/api/v1/schedules/{id}/days` | `schedule:monthly:view` | 排班日明细，嵌套班次、人员（含 shift_def、person 关联信息） |

## 数据范围

列表查询通过 `resolve_scoped_org_unit_ids(db, user)` 获取用户可见的 org_unit ID 集合：

| 用户数据范围 | 行为 |
|---|---|
| `all`（全局） | 不限制，可查看全部台站机房排班 |
| `room` / `station` | 仅查看指定机房及其子机房的排班 |
| `self` | 仅查看本人所属机房的排班 |
| 无范围 | 返回空列表 |

服务层 `list_schedules` 接收 `org_unit_ids` 参数：
- `None` → 全局，不附加 org_unit 过滤
- 空 `set()` → 无可见范围，返回空
- 非空 `set[int]` → 附加 `MonthlySchedule.org_unit_id.in_(org_unit_ids)` 过滤
