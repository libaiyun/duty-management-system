## API 端点

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| GET | `/api/v1/schedules` | 列表（按机房、状态筛选；分页；数据范围） | `schedule:monthly:view` |
| GET | `/api/v1/schedules/{id}` | 详情 | `schedule:monthly:view` |
| GET | `/api/v1/schedules/{id}/days` | 日班次明细（可选 `year`/`month` 按月过滤） | `schedule:monthly:view` |
| **GET** | `/api/v1/schedules/{id}/days/range` | 按日期范围查询（`from`/`to` 必填） | `schedule:monthly:view` |

### 新增参数

**GET `/api/v1/schedules/{id}/days`**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `year` | int | 否 | 年份，不传返回全部 |
| `month` | int | 否 | 月份（1-12），需与 `year` 同传 |

**GET `/api/v1/schedules/{id}/days/range`**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `from` | date | 是 | 起始日期（yyyy-MM-dd） |
| `to` | date | 是 | 结束日期（yyyy-MM-dd），必须 >= from |

### 错误码

| 场景 | HTTP | code |
|------|------|------|
| 排班不存在 | 404 | NOT_FOUND |
| 无权限 | 403 | FORBIDDEN |
| from > to | 422 | BUSINESS_RULE_FAILED |

## 临时手动验证

```bash

curl -H "Authorization: Bearer $TOKEN" \
  "http://localhost:8000/api/v1/schedules/1/days?year=2026&month=7"

# 按日期范围查询
curl -H "Authorization: Bearer $TOKEN" \
  "http://localhost:8000/api/v1/schedules/1/days/range?from=2026-07-01&to=2026-07-31"

# from > to 校验
curl -H "Authorization: Bearer $TOKEN" \
  "http://localhost:8000/api/v1/schedules/1/days/range?from=2026-12-31&to=2026-01-01"
# 返回: {"code":"BUSINESS_RULE_FAILED","message":"起始日期不能晚于结束日期"}
```
