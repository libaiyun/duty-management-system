## 页面布局

```
┌──────────────────────────────────────────────────────┐
│  台站机房                                              │
│  [新增台站] [新增机房]                                   │
├──────────────────┬───────────────────────────────────┤
│  搜索组织...       │  台站名称（选中节点）                  │
│                  │  ┌─────────────────────────────┐  │
│  [台站] 发射台A    │  │ 编码: station-1            │  │
│  [机房] 机房A-1   │  │ 名称: 发射台A               │  │
│  [机房] 机房A-2   │  │ 类型: 台站                  │  │
│  [台站] 发射台B    │  │ 状态: 启用                  │  │
│  [机房] 机房B-1   │  └─────────────────────────────┘  │
│                  │  [编辑] [停用] [删除]               │
└──────────────────┴───────────────────────────────────┘
```

## 页面功能

| 功能 | 说明 | API |
|------|------|-----|
| 组织树 | 左侧 el-tree 展示台站-机房层级 | GET `/org-units/tree` |
| 搜索过滤 | 按名称过滤树节点 | — |
| 查看详情 | 点击树节点，右侧展示编码/名称/类型/状态 | — |
| 新增台站 | 弹窗表单，填写编码+名称 | POST `/org-units` |
| 新增机房 | 弹窗表单，自动填入选中台站为上级 | POST `/org-units` |
| 编辑 | 编辑名称 | PUT `/org-units/{id}` |
| 停用/启用 | 确认弹窗后切换 status | PUT `/org-units/{id}` |
| 删除 | 确认弹窗后删除 | DELETE `/org-units/{id}` |

## 说明

- 页面依赖后端 API：`GET /org-units/tree`、`POST /org-units`、`PUT /org-units/{id}`、`DELETE /org-units/{id}`。
- 删除操作后端校验是否存在子节点，有子节点时返回 409 并在前端显示通用错误提示。
- 新增/编辑表单当前只包含编码和名称，负责人字段暂不展示。
- 页面样式遵循现有 BEM 命名风格（`.org-unit-view__*`）。
