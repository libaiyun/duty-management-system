# 原型设计

## 1. 设计范围与原则

本文基于 `docs/design/01-需求分析.md` 设计广播电视台站值班管理系统原型。首期以 B/S 后台 Web 系统为主，覆盖多台站、多机房、人员账号、自动排班、换班、请假、顶班、审批、退费计算、考勤和报表导出。微信小程序首期不实现，仅在审批能力上预留后续扩展。

原型默认规则：

- 支持多个台站、多个机房独立排班。
- 主城区台站一般双岗值，每个班次 2 名值机员。
- 广播发射台班次为早班、中班、晚班，排班规则支持广播发射台固定轮班规则。
- 排班发布后管理员可修改，无需审批，但需要操作日志。
- 换班由本人发起，可互换或单向替班，对方确认后由机房主任审批。
- 请假由本人发起，机房主任审批；法定节假日不允许请假。
- 请假获批后由机房主任安排顶班，顶班人需要确认。
- 考勤、补贴退费按实际值班对象计算。
- 首期报表导出 Excel，并保留导出历史。

## 5. 全局页面布局

### 5.1 Web 后台布局

- 顶部栏：系统名称、当前台站/机房切换、消息提醒、当前用户、退出登录。
- 左侧菜单：按角色权限显示一级和二级菜单。
- 内容区：面包屑、页面标题、查询区、操作区、主表格/日历/表单区、分页区。
- 右侧抽屉：用于详情查看、审批记录、流程轨迹。
- 弹窗：用于新增、编辑、确认、计算、导出等短流程操作。

### 5.2 列表页标准布局

- 第一行：页面标题 + 主操作按钮。
- 第二行：查询条件，默认折叠高级条件。
- 第三行：批量操作按钮或提示条。
- 主区域：表格。
- 底部：分页、总数、导出入口。

### 5.3 表单页/弹窗标准布局

- 顶部：表单标题和业务状态。
- 中部：基础信息、业务信息、附件/说明、审批记录。
- 底部：取消、暂存、提交、同意、拒绝等按钮。

## 6. 状态流转

### 6.1 月度排班状态

```text
未生成 -> 草稿 -> 已发布 -> 已锁定
草稿 -> 已作废
已发布 -> 已调整
已调整 -> 已发布
```

- 未生成：当前月份尚未排班。
- 草稿：系统已生成或人工维护，未对普通用户生效。
- 已发布：普通用户可查看并发起换班/请假。
- 已调整：发布后管理员修改过，需重新发布或保留调整记录。
- 已锁定：历史考勤或退费已锁定，不允许修改排班。
- 已作废：重新生成前废弃旧草稿。

### 6.2 换班状态

```text
草稿 -> 待对方确认 -> 待主任审批 -> 已通过 -> 已生效
待对方确认 -> 对方拒绝
待主任审批 -> 审批拒绝
草稿/待对方确认/待主任审批 -> 已撤回
已通过/已生效 -> 已作废
```

### 6.3 请假状态

```text
草稿 -> 待主任审批 -> 已通过 -> 待安排顶班 -> 待顶班确认 -> 已完成
待主任审批 -> 审批拒绝
草稿/待主任审批 -> 已撤回
已通过/待安排顶班/待顶班确认 -> 已作废
```

### 6.4 顶班状态

```text
待安排 -> 待顶班人确认 -> 已确认 -> 已生效
待顶班人确认 -> 顶班人拒绝 -> 待重新安排
已生效 -> 已作废
```

### 6.5 退费批次状态

```text
未计算 -> 已计算 -> 已复核 -> 已锁定 -> 已导出
已计算/已复核 -> 重新计算
```

### 6.6 导出任务状态

```text
生成中 -> 成功
生成中 -> 失败
成功 -> 已下载
```

## 7. 页面原型明细

### 7.1 登录页

| 项目 | 说明 |
| --- | --- |
| 页面名称 | 登录页 |
| 页面用途 | 用户通过账号密码登录系统，后续可扩展微信绑定登录。 |
| 页面元素 | 系统名称、账号输入框、密码输入框、记住登录、登录按钮、微信绑定登录入口、错误提示区。 |
| 页面流程 | 输入账号密码；点击登录；校验成功进入工作台首页；失败显示错误。 |
| 页面之间关系 | 登录成功跳转工作台首页；微信绑定入口进入账号绑定流程。 |

- 页面布局：居中登录面板，底部显示系统版本和单位名称。
- 表格字段：无。
- 查询条件：无。
- 操作按钮：登录、微信登录/绑定。
- 表单设计：账号必填；密码必填；记住登录可选。
- 弹窗设计：首次微信绑定弹窗，字段为系统账号、密码、微信用户确认信息。
- 页面交互：回车触发登录；密码错误后保留账号；连续失败显示验证码预留位。
- 异常提示：账号不存在；密码错误；账号停用；无系统权限；网络异常。
- 权限控制：未登录用户只能访问登录页。

### 7.2 工作台首页

| 项目 | 说明 |
| --- | --- |
| 页面名称 | 工作台首页 |
| 页面用途 | 展示当前用户最常用的排班、待办、提醒和月度概览。 |
| 页面元素 | 今日值班卡片、我的下次值班、待办审批、待确认换班/顶班、月度排班状态、退费批次状态、快捷入口。 |
| 页面流程 | 登录后进入；系统按角色加载卡片；用户点击卡片进入对应页面。 |
| 页面之间关系 | 跳转到我的排班、待办审批、月度排班、退费计算、月度考勤。 |

- 页面布局：上方统计卡片，中间待办列表，右侧快捷入口，下方月度信息概览。
- 表格字段：待办类型、业务单号、申请人、班次日期、当前状态、到达时间、操作。
- 查询条件：台站、机房、月份，仅管理角色显示。
- 操作按钮：查看排班、处理待办、生成排班、计算退费、导出考勤。
- 表单设计：无主表单，仅台站/机房切换控件。
- 弹窗设计：消息提醒弹窗，展示待处理事项摘要。
- 页面交互：点击统计卡片自动带入筛选条件；待办数量实时刷新或页面刷新后更新。
- 异常提示：当前用户未绑定人员；当前月份未生成排班；存在未处理顶班缺岗。
- 权限控制：普通用户只看本人数据；主任看所属机房；管理员看授权范围。

### 7.3 我的排班页

| 项目 | 说明 |
| --- | --- |
| 页面名称 | 我的排班页 |
| 页面用途 | 查看本人月度排班、实际值班、换班和请假入口。 |
| 页面元素 | 月份选择、日历视图、列表视图、班次标签、状态标记、发起换班、发起请假、导出本人排班。 |
| 页面流程 | 选择月份；查看本人班次；选择某个已发布班次；可发起换班或请假。 |
| 页面之间关系 | 可打开发起换班弹窗、发起请假弹窗；跳转我的换班页、我的请假页。 |

- 页面布局：顶部月份切换；主体为月历，右侧显示选中日期详情；可切换为表格。
- 表格字段：日期、星期、台站、机房、班次、班次时间、原排班人员、实际值班人员、业务状态、操作。
- 查询条件：月份、台站、机房、班次、状态。
- 操作按钮：发起换班、发起请假、查看详情、导出。
- 表单设计：无主表单。
- 弹窗设计：发起换班弹窗、发起请假弹窗。
- 页面交互：法定节假日班次禁用请假按钮；已锁定月份禁用换班和请假；存在待审批业务时提示不能重复申请。
- 异常提示：排班未发布；该班次已有换班/请假流程；法定节假日不允许请假。
- 权限控制：只能查看本人排班；主任可通过排班管理查看全员排班。

### 7.4 我的换班页

| 项目 | 说明 |
| --- | --- |
| 页面名称 | 我的换班页 |
| 页面用途 | 发起、查看、撤回本人换班申请，并处理他人发给自己的换班确认。 |
| 页面元素 | 换班列表、状态标签、申请详情、对方确认区、审批记录、撤回/作废操作。 |
| 页面流程 | 发起申请；对方确认；主任审批；审批通过后更新实际值班。 |
| 页面之间关系 | 从我的排班进入；可跳转审批详情；通过后影响实际值班页和考勤。 |

- 页面布局：上方查询区；中间 Tab 分为我发起的、待我确认、与我相关；下方表格。
- 表格字段：申请单号、换班类型、原班次日期、原班次、申请人、目标人员、目标班次、状态、提交时间、操作。
- 查询条件：月份、申请类型、状态、申请人、目标人员、班次日期。
- 操作按钮：新增换班、查看、确认同意、拒绝、撤回、作废。
- 表单设计：换班类型为互换/单向替班；原班次必选；目标人员必选；目标班次互换时必选；原因可选。
- 弹窗设计：发起换班弹窗、确认同意弹窗、拒绝原因弹窗、撤回确认弹窗、作废确认弹窗。
- 页面交互：选择原班次后过滤可选目标人员；单向替班不要求目标班次；跨月份时提示会影响两个考勤月份。
- 异常提示：目标人员无账号；目标班次已锁定；申请已被处理不能重复操作。
- 权限控制：本人可发起和撤回；目标人员可确认；机房主任审批；管理员仅可查看或作废异常单。

### 7.5 我的请假页

| 项目 | 说明 |
| --- | --- |
| 页面名称 | 我的请假页 |
| 页面用途 | 值机员提交公休假、事假、病假申请并查看审批、顶班进度。 |
| 页面元素 | 请假申请列表、新增请假、请假详情、审批状态、顶班状态。 |
| 页面流程 | 选择本人班次；填写请假类型和原因；提交主任审批；通过后等待顶班安排和确认。 |
| 页面之间关系 | 从我的排班发起；通过后进入顶班安排页；结果同步实际值班和考勤。 |

- 页面布局：查询区 + 列表；详情使用右侧抽屉展示审批和顶班轨迹。
- 表格字段：申请单号、请假类型、班次日期、班次、申请人、审批状态、顶班状态、提交时间、操作。
- 查询条件：月份、请假类型、审批状态、顶班状态、班次日期。
- 操作按钮：新增请假、查看、撤回、作废。
- 表单设计：请假类型必填；请假班次必填；请假原因可选；无需上传材料。

## 12. 页面交互规则

- 台站和机房切换后，所有列表按数据范围重新加载。
- 月份选择默认当前月；排班、考勤、退费支持查看历史月份。
- 业务单号可点击打开详情抽屉。
- 状态标签统一使用颜色区分：草稿灰色、待处理橙色、通过绿色、拒绝红色、锁定蓝色、作废深灰。
- 发起换班、请假时优先从排班页带入班次，减少重复录入。
- 主任审批同意请假后，系统自动产生待安排顶班事项。
- 顶班人拒绝后，主任端出现重新安排提醒。
- 换班、请假、顶班生效后，实际值班页自动更新。
- 退费和考勤计算前检查未完成业务，存在异常时给出清单。
- 导出操作进入异步任务，用户在导出历史下载。
- 历史月份锁定后，排班、换班、请假、顶班、退费、考勤均不可再修改。

## 13. 异常提示规则

| 场景 | 提示文案 |
| --- | --- |
| 未配置排班规则 | 当前机房未配置排班规则，无法生成排班。 |
| 值机员不足 | 参与排班人员不足，无法满足每班双岗值要求。 |
| 法定节假日请假 | 法定节假日班次不允许请假。 |
| 重复申请 | 当前班次已有未完成的换班或请假申请。 |
| 无审批权限 | 你没有处理该审批事项的权限。 |
| 顶班未确认 | 存在未确认顶班，实际值班结果尚未完整。 |
| 月份已锁定 | 当前月份已锁定，不允许修改。 |
| 退费无法计算 | 实际值班数据未生成或存在未完成业务，无法计算退费。 |
| 导出无数据 | 当前条件下没有可导出的数据。 |
| 文件不存在 | 导出文件不存在或已归档，请重新生成。 |
| 账号未绑定人员 | 当前账号未绑定人员档案，请联系管理员。 |
| 数据被引用 | 当前数据已被业务引用，不能删除。 |

## 14. 权限控制

### 14.1 菜单权限

| 角色 | 可见菜单 |
| --- | --- |
| 值机员 | 工作台、我的排班、我的换班、我的请假、我的顶班、本人退费明细、本人考勤 |
| 检修班人员 | 工作台、我的顶班、本人考勤、本人退费明细 |
| 机房主任 | 工作台、审批中心、排班管理、请假顶班、退费管理、考勤报表、本机房基础数据只读或授权维护 |
| 机房副主任 | 工作台、我的顶班、本机房排班和考勤只读，按授权参与审批 |
| 排班管理员 | 排班管理、实际值班、月度值班表导出、人员排班属性只读 |
| 财务/统计人员 | 退费管理、月度考勤、导出历史 |
| 系统管理员 | 全部菜单 |

### 14.2 数据权限

- 本人数据：值机员、检修班人员只能查看本人排班、申请、顶班、考勤和退费。
- 机房数据：机房主任查看和管理所属机房数据。
- 台站数据：台站级管理员查看授权台站下全部机房。
- 全局数据：系统管理员查看和维护全局基础资料和系统配置。
- 审批数据：审批人只能处理分配给自己的待办事项。

### 14.3 操作权限

| 操作 | 权限规则 |
| --- | --- |
| 生成排班 | 排班管理员、机房主任、系统管理员 |
| 修改排班 | 排班管理员、机房主任、系统管理员；锁定后禁止 |
| 发起换班 | 班次所属值机员本人 |
| 确认换班 | 目标人员本人 |
| 审批换班 | 所属机房主任 |
| 发起请假 | 班次所属值机员本人 |
| 审批请假 | 所属机房主任 |
| 安排顶班 | 所属机房主任 |
| 确认顶班 | 顶班人本人 |
| 计算退费 | 财务/统计、机房主任、系统管理员 |
| 导出报表 | 具备对应数据查看权限的用户 |
| 锁定月份 | 机房主任、财务/统计、系统管理员按业务范围操作 |
| 管理账号角色 | 系统管理员 |
| 查看操作日志 | 系统管理员；主任可查看本机房业务日志 |
