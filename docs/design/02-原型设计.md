# 原型设计

## 1. 设计范围与原则

本文基于 `docs/design/01-需求分析.md` 设计广播电视台站值班管理系统原型。首期以 B/S 后台 Web 系统为主，覆盖多台站、多机房、人员账号、排班规则、排班、换班、请假、顶班、审批、退费计算、考勤和报表导出。微信小程序首期不实现，仅在审批能力上预留后续扩展。

原型默认规则：

- 支持多个台站、多个机房独立排班。
- 每格人数按机房可配置，所有格子统一。典型场景为主城区台站双岗值。
- 排班规则采用 N 天循环表格驱动，表格列数由班次定义决定，不写死为三班。
- 规则支持草稿/发布/重新发布，发布后普通用户可见排班。
- 排班只生成一次，跨月自动延续，按月切片展示和导出。
- 换班由本人发起，可互换或单向替班，对方确认后由机房主任审批。
- 请假由本人发起，机房主任审批；法定节假日不允许请假。
- 请假获批后由机房主任安排顶班，顶班人需要确认。
- 考勤、补贴退费按实际值班对象计算。
- 首期报表导出 Excel，并保留导出历史。

## 5. 全局页面布局

### 5.1 Web 后台布局

- 顶部栏：系统名称、消息提醒（未读红点）、当前用户和机房名（格式"姓名 · 机房名"）、退出登录。
  - **普通用户**：机房名为只读文本，不显示台站，不提供切换功能。
  - **系统管理员**：同位置显示可点击的机房切换下拉框，切换后所有机房相关页面数据范围随之更新。打开全局页面（台站机房、账号角色、操作日志、备份归档）时自动隐藏切换器。
- 左侧菜单：按角色权限显示，非本角色可用的菜单不展示。
- 内容区：面包屑、页面标题、查询区、操作区、主表格/日历/表单区、分页区。
- 右侧抽屉：用于详情查看、审批记录、流程轨迹。
- 弹窗：用于新增、编辑、确认、计算、导出等短流程操作。

> **设计修订说明：** 一人一机房，登录后自动进入所属机房。前端不展示台站概念，所有页面数据按用户所属机房自动筛选。详见 `06-设计修订.md`。

### 5.2 列表页标准布局

- 第一行：页面标题 + 主操作按钮。
- 第二行：查询条件，默认折叠高级条件。
- 第三行：批量操作按钮或提示条。
- 主区域：表格。
- 底部：分页、总数、导出入口。

### 5.3 表单页/弹窗标准布局

- 顶部：表单标题和业务状态。
- 中部：基础信息、业务信息、附件/说明、审批记录。
- 底部：取消、暂存、提交、同意、拒绝等按钮。

## 6. 状态流转

### 6.1 排班规则状态

```text
草稿 -> 已发布
已发布 -> 草稿（重新配置后再发布）
```

- 草稿：规则未发布，普通用户不可见排班。
- 已发布：规则生效，系统从起始日期起生成全部排班，普通用户可查看并发起换班/请假。
- 重新发布：修改规则后再次发布，起始日期前保留、起始日期起覆盖刷新。

### 6.2 排班状态

```text
已生成 -> 已调整 -> 已发布 -> 已锁定
已生成 -> 已发布
```

- 已生成：规则发布后，系统从起始日期起循环生成全部日期排班。
- 已调整：排班管理员手工修改过个别日期人员。
- 已发布：排班对普通用户可见。
- 已锁定：历史月份考勤或退费已锁定，该月内排班不允许修改。

### 6.3 换班状态

```text
草稿 -> 待对方确认 -> 待主任审批 -> 已通过 -> 已生效
待对方确认 -> 对方拒绝
待主任审批 -> 审批拒绝
草稿/待对方确认/待主任审批 -> 已撤回
已通过/已生效 -> 已作废
```

### 6.4 请假状态

```text
草稿 -> 待主任审批 -> 已通过 -> 待安排顶班 -> 待顶班确认 -> 已完成
待主任审批 -> 审批拒绝
草稿/待主任审批 -> 已撤回
已通过/待安排顶班/待顶班确认 -> 已作废
```

### 6.5 顶班状态

```text
待安排 -> 待顶班人确认 -> 已确认 -> 已生效
待顶班人确认 -> 顶班人拒绝 -> 待重新安排
已生效 -> 已作废
```

### 6.6 退费批次状态

```text
未计算 -> 已计算 -> 已复核 -> 已锁定 -> 已导出
已计算/已复核 -> 重新计算
```

### 6.7 导出任务状态

```text
生成中 -> 成功
生成中 -> 失败
成功 -> 已下载
```

## 7. 页面原型明细

### 7.1 登录页

| 项目 | 说明 |
| --- | --- |
| 页面名称 | 登录页 |
| 页面用途 | 用户通过账号密码登录系统，后续可扩展微信绑定登录。 |
| 页面元素 | 系统名称、账号输入框、密码输入框、记住登录、登录按钮、微信绑定登录入口、错误提示区。 |
| 页面流程 | 输入账号密码；点击登录；校验成功进入工作台首页；失败显示错误。 |
| 页面之间关系 | 登录成功跳转工作台首页；微信绑定入口进入账号绑定流程。 |

- 页面布局：居中登录面板，底部显示系统版本和单位名称。
- 表格字段：无。
- 查询条件：无。
- 操作按钮：登录、微信登录/绑定。
- 表单设计：账号必填；密码必填；记住登录可选。
- 弹窗设计：首次微信绑定弹窗，字段为系统账号、密码、微信用户确认信息。
- 页面交互：回车触发登录；密码错误后保留账号；连续失败显示验证码预留位。
- 异常提示：账号不存在；密码错误；账号停用；无系统权限；网络异常。
- 权限控制：未登录用户只能访问登录页。

### 7.2 工作台首页

| 项目 | 说明 |
| --- | --- |
| 页面名称 | 工作台首页 |
| 页面用途 | 按角色展示当前用户最常用的值班、待办、提醒和概览信息。系统自动确定用户所属机房，无需手动选择。 |
| 页面元素 | 按角色差异化展示卡片（详见下方角色内容表）；快捷入口（排班表、审批中心、退费管理等）。 |
| 页面流程 | 登录后自动进入；系统按角色加载对应卡片；点击卡片或快捷入口进入对应页面。 |
| 页面之间关系 | 跳转到排班表、审批中心、退费管理、月度考勤等。 |

- 页面布局：上方统计卡片，中间待办列表，右侧快捷入口，下方月度信息概览。
- 角色内容差异：

| 角色 | 展示内容 |
| --- | --- |
| 值机员 | 今日当班卡片、本人下次值班日期、待确认换班提醒、近期换班/请假状态 |
| 检修班 | 待确认顶班列表、已确认近期顶班 |
| 副主任 | 同机房主任（本机房今日值班一览、待审批数量、待安排顶班数量、规则发布状态） |
| 机房主任 | 本机房今日各班次在岗人员一览、待审批数量、待安排顶班数量、规则发布状态 |
| 排班管理员 | 本机房规则状态、近期排班变更提醒、月末导出提醒 |
| 财务/统计 | 待计算退费月份列表、待生成考勤月份、最近批次状态 |
| 系统管理员 | 系统告警、备份状态、快捷入口（账号角色、台站机房、操作日志），顶部切换器选择机房后可查看该机房概览 |

- 表格字段：待办类型、业务单号、申请人、班次日期、当前状态、到达时间、操作。
- 查询条件：机房上下文由系统自动确定，无台站/机房切换控件。
- 操作按钮：查看排班、处理待办、发布规则、计算退费、导出考勤。
- 表单设计：无主表单。
- 弹窗设计：消息提醒弹窗，展示待处理事项摘要。
- 页面交互：点击统计卡片自动带入筛选条件；待办数量实时刷新或页面刷新后更新。
- 异常提示：当前用户未绑定人员；当前机房排班规则未发布；存在未处理顶班缺岗。
- 权限控制：普通用户只看本人数据；主任看所属机房全部；管理员通过顶部切换器切换机房。

### 7.3 排班表

> **设计修订：** 合并原"排班日历页""排班明细页"和"我的排班页"为一个页面，支撑日历和列表双视图。

| 项目 | 说明 |
| --- | --- |
| 页面名称 | 排班表 |
| 页面用途 | 按日历或列表视图展示本机房全员排班，值机员查看本人班次并发起换班/请假，主任/管理员可编辑调整。 |
| 页面元素 | 顶部月份切换、视图切换按钮组 [日历/列表]、锁定状态标签、导出按钮；日历视图月历网格；列表视图按月表格筛选。 |
| 页面流程 | 登录后打开即显示本机房当月排班；值机员点击本人高亮格子发起换班或请假；主任/管理员点击任意格子编辑人员。 |
| 页面之间关系 | 从工作台今日值班进入；可打开发起换班弹窗、发起请假弹窗、编辑人员弹窗。 |

- 页面布局：顶部控制区（月份、视图切换、锁定状态、导出）；主体为日历月历或列表视图。
- 日历视图：月历网格，每格内按班次分行显示人员（行数 = 每格人数 × 班次数）。本人日期格浅绿底色高亮，法定节假日日期格浅红底色并标注节假名称，已锁定月份格子置灰。缺岗/异常在人员名后用小标签标注（"已换"、"请假"），点击查看详情。
- 列表视图表格字段：日期、星期、是否节假日、各班次人员（列标题动态来自 shift_def）、异常标记、操作。
- 查询条件：日期范围、班次、人员、异常类型（列表视图）。机房上下文自动确定。
- 操作按钮：
  - 值机员：点击本人高亮格子 → 弹出菜单（"发起换班" / "发起请假"），法定节假日"发起请假"置灰。
  - 主任/管理员：点击任意格子 → "编辑人员"弹窗；点击本人格子时额外显示"换班""请假"选项。**不在此处发起顶班**（顶班前置条件是请假审批通过，统一走请假记录页）。
- 表单设计：编辑人员弹窗字段为日期、班次、原人员、调整后人员、调整原因。
- 弹窗设计：编辑人员弹窗、发起换班弹窗、发起请假弹窗、人员冲突提示弹窗。
- 页面交互：月份切换默认本月；视图切换保留月份和筛选条件；法定节假日带标记；已锁定月份所有编辑入口置灰；数据按本机房自动筛选。
- 异常提示：排班未发布；该班次已有换班/请假流程；法定节假日不允许请假；已锁定不可编辑；人员不足。
- 权限控制：值机员只读（本人高亮，可发起换班请假）；主任/排班管理员可编辑；财务/统计只读。

### 7.4 换班申请页

> **设计修订：** 保持个人视角，无论什么角色打开，看到的都是本人相关数据。机房级别的换班管理走审批中心。

| 项目 | 说明 |
| --- | --- |

| 业务发起 | 发起换班、发起请假 | 排班表、换班申请、请假申请 |
| 审批确认 | 同意、拒绝、确认顶班 | 审批中心、我的顶班 |
| 排班 | 发布规则、重新发布、编辑人员、锁定 | 排班规则、排班表 |
| 顶班 | 安排顶班、重新安排 | 请假记录 |
| 计算 | 计算、重新计算、复核、锁定 | 退费管理、月度考勤 |
| 导出 | 导出 Excel、下载、重新生成 | 报表和导出历史 |
| 风险操作 | 撤回、作废、停用、删除、归档、恢复申请 | 各管理页 |

## 12. 页面交互规则

- 所有页面数据按用户所属机房自动筛选，前端不提供机房切换控件（系统管理员除外）。
- 系统管理员通过顶部切换器选择机房后，机房相关页面数据随之更新。全局页面（台站机房、账号角色、操作日志、备份归档）打开时自动隐藏切换器。
- 月份选择默认当前月；排班、考勤、退费支持按月切片查看和导出。
- 排班规则发布后，系统自动从起始日期起生成全部排班数据。
- 排班规则重新发布时，起始日期前保留、起始日期起覆盖刷新。
- 业务单号可点击打开详情抽屉。
- 状态标签统一使用颜色区分：草稿灰色、待处理橙色、通过绿色、拒绝红色、锁定蓝色、作废深灰。
- 发起换班、请假时优先从排班页带入班次，减少重复录入。
- 主任审批同意请假后，系统自动产生待安排顶班事项。
- 顶班人拒绝后，主任端出现重新安排提醒。
- 换班、请假、顶班生效后，实际值班页自动更新。
- 退费和考勤计算前检查未完成业务，存在异常时给出清单。
- 导出操作进入异步任务，用户在导出历史下载。
- 历史月份锁定后，排班、换班、请假、顶班、退费、考勤均不可再修改。

## 13. 异常提示规则

| 场景 | 提示文案 |
| --- | --- |
| 未配置排班规则 | 当前机房未配置排班规则或规则未发布，无法查看排班。 |
| 人员不足 | 规则表格中某格人数不达标或人员不属于当前机房。 |
| 法定节假日请假 | 法定节假日班次不允许请假。 |
| 重复申请 | 当前班次已有未完成的换班或请假申请。 |
| 无审批权限 | 你没有处理该审批事项的权限。 |
| 顶班未确认 | 存在未确认顶班，实际值班结果尚未完整。 |
| 月份已锁定 | 当前月份已锁定，不允许修改。 |
| 退费无法计算 | 实际值班数据未生成或存在未完成业务，无法计算退费。 |
| 导出无数据 | 当前条件下没有可导出的数据。 |
| 文件不存在 | 导出文件不存在或已归档，请重新生成。 |
| 账号未绑定人员 | 当前账号未绑定人员档案，请联系管理员。 |
| 数据被引用 | 当前数据已被业务引用，不能删除。 |
| 系统管理员未选中机房 | 请在顶部选择机房后再操作。 |
| 机房未配置班次 | 当前机房未配置班次定义，无法设置排班规则。 |

### 14.2 数据权限

- 本人数据：值机员、检修班人员只能查看本人排班、申请、顶班、考勤和退费。
- 机房数据：机房主任、副主任、排班管理员、财务/统计人员的数据范围限定在所属机房；一人一机房，登录后自动确定。
- 全局数据：系统管理员通过顶部切换器选择机房后查看该机房数据；台站机房、账号角色、操作日志、备份归档等全局页面不依赖机房上下文。
