# 需求分析

## 1. 文档范围

本文基于 `docs/需求文档.md` 梳理广播电视台站值班管理系统的业务需求、业务模块、流程、角色、权限、数据实体、需求缺失与冲突，以及后续需要确认的问题。

系统目标是建设一个 B/S 架构的值班管理系统，支持值机员管理、自动排班、换班审批、请假与顶班、补贴/退费计算、月度报表导出，并支持微信小程序审批。

## 2. 业务需求梳理

### 2.1 值机员管理

- 支持添加值机员。
- 支持对值机员进行简单设置，用于后续排班规则配置。
- 值机员应具备账号，用于登录、发起换班、审批确认等操作。
- 值机员可能按台站、班组、岗位或排班规则参与排班。

### 2.2 台站与排班规则

- 系统面向广播电视台站，且不同台站排班方式可能不同。
- 排班规则采用 N 天循环表格驱动，管理员在 N 天 × M 班的表格中为每格直接选择值机员。M 为机房启用的班次数，由班次定义决定。
- 每个机房一套独立规则，配置循环天数 N、起始日期、每格人数（所有格子统一）。
- 规则支持草稿/发布状态流转，发布后普通用户可见，可重新发布生成新版本。
- 配置示例（广发台 6 天 3 班制、地球站 5 天 3 班制）仅作参考，不写死为系统算法。详见 `docs/design/05-排班规则设计.md`。

### 2.3 排班生成

- 排班由规则表驱动：管理员配置 N 天 × M 班的人员表格并发布后，系统从起始日期起循环写入全部日期排班。
- 排班只生成一次，跨月自动延续，前端按月切片展示和导出。
- 排班结果应覆盖每天每个班次。
- 排班结果应能作为换班、请假、顶班、考勤、补贴和退费计算的基础数据。

### 2.4 值班表导出

- 支持导出按月切片的值班表。
- 导出内容至少包含：
  - 日期
  - 星期
  - 各班次人员（列标题来自班次定义）
- 导出格式未明确，可能需要支持 Excel 或其他办公格式。

### 2.5 换班

- 支持值机员之间换班。
- 换班流程包含：
  - 账号管理
  - 对方同意
  - 领导审批
- 换班应影响实际值班人员、考勤、补贴和退费计算。
- 换班申请应保留流程记录和审批状态。

### 2.6 请假

- 支持公休假。
- 支持事假。
- 支持病假。
- 当值机员请假且不是换班时，由机房主任安排检修班同志或机房正副主任顶班。
- 法定节假日值机员不得请假。
- 请假审批流程未明确，但结合系统存在微信小程序审批，预计请假也应纳入审批。

### 2.7 顶班

- 顶班适用于值机员请假且不走换班的场景。
- 顶班人来源包括：
  - 检修班人员
  - 机房主任
  - 机房副主任
- 顶班由机房主任安排。
- 顶班人参与法定节假日退费和餐补退费计算。
- 顶班记录应与原排班、请假记录、实际值班记录关联。

### 2.8 餐补退费计算

- 餐补标准：
  - 早班：10 元/人/班
  - 中班：10 元/人/班
  - 晚班：14 元/人/班
- 餐补按班次每月随工资发放。
- 当前广发台实际值班中，中班值机员承担一部分晚班，晚班值机员负责剩余部分晚班。
- 因晚班值机员已按晚班拿到 14 元，但中班值机员承担部分晚班工作，所以晚班值机员需退给中班值机员 4 元。
- 系统应计算餐补退费，并支持导出退费表。
- 顶班人也应参与餐补退费计算。

### 2.9 法定节假日加班费退费计算

- 法定节假日当天 00:00-24:00 的三个班次均计算节日加班费。
- 加班费标准为 150 元/人/班。
- 法定节假日加班费每月随工资发放。
- 当前广发台实际值班中，中班值机员承担一部分晚班，晚班值机员负责剩余部分晚班。
- 晚班值机员已拿到 150 元，但需退给中班值机员 56 元。
- 系统应计算法定节假日加班费退费，并支持导出退费表。
- 顶班人也应参与法定节假日退费计算。

### 2.10 退费方式与退费表

- 退费方式为微信群内自行发红包。
- 系统不直接处理支付。
- 系统需要导出退费表，用于指导人员之间发红包。
- 退费表应至少体现：
  - 退费月份
  - 退费类型
  - 应退人员
  - 应收人员
  - 金额
  - 来源班次或日期
  - 是否与顶班、换班、请假有关

### 2.11 月度考勤表导出

- 支持导出月度考勤表。
- 考勤表应基于排班、换班、请假、顶班后的实际值班结果生成。
- 考勤统计口径未明确。

### 2.12 微信小程序审批

- 支持通过微信小程序进行审批。
- 可能涉及：
  - 换班对方确认
  - 领导审批
  - 请假审批
  - 顶班确认
- 小程序是否仅用于审批，还是同时支持查看排班、发起申请，需求未明确。

## 4. 业务流程整理

### 4.1 人员与排班初始化流程

1. 管理员或机房主任维护台站信息。
2. 维护值机员、检修班人员、主任/副主任等人员信息。
3. 为人员创建或绑定账号。
4. 配置排班规则（循环天数 N、起始日期、N×M 网格人员选择）。
5. 配置餐补、法定节假日加班费、退费标准。

### 4.2 排班生成流程

1. 排班管理员配置排班规则（设置循环天数 N、起始日期、为每格选择值机员）。
2. 保存规则并发布。
3. 系统从起始日期起，按 N 天循环读取规则表，为每个日期每个班次生成对应人员排班。
4. 排班跨月自动延续，用户按月切片查看。
5. 排班管理员可手工调整个别日期人员。
6. 支持按月导出值班表。

### 4.3 换班流程

1. 值机员登录系统，选择本人某个已排班班次发起换班申请。
2. 申请人选择换班对象和目标班次。
3. 对方收到换班申请并确认同意或拒绝。
4. 对方同意后，提交领导审批。
5. 领导审批通过后，系统更新实际值班安排。
6. 换班结果进入考勤、补贴和退费计算。
7. 审批拒绝或对方拒绝时，原排班不变。

### 4.4 请假与顶班流程

1. 值机员对某个班次发起请假申请或由管理人员登记请假。
2. 系统校验该班次是否为法定节假日。
3. 若为法定节假日，禁止请假。
4. 非法定节假日情况下，请假进入审批或登记流程。
5. 请假获批后，机房主任安排检修班人员、机房主任或副主任顶班。
6. 顶班安排确认后，系统更新实际值班记录。
7. 请假和顶班结果进入考勤、补贴和退费计算。

### 4.5 餐补退费计算流程

1. 系统读取指定月份实际值班记录。
2. 识别晚班值机员和承担部分晚班工作的中班值机员。
3. 根据退费规则计算晚班值机员应退给中班值机员的金额。
4. 如果存在换班、请假或顶班，按实际值班人员参与计算。
5. 生成餐补退费明细。
6. 导出退费表，人员按微信群红包方式自行退费。

### 4.6 法定节假日加班费退费计算流程

1. 系统读取法定节假日日期和月度实际值班记录。
2. 识别法定节假日当天 00:00-24:00 的各班次。
3. 识别晚班值机员和承担部分晚班工作的中班值机员。
4. 根据每班 150 元和退费 56 元规则计算退费明细。
5. 如果存在换班或顶班，按实际值班人员参与计算。
6. 生成法定节假日加班费退费明细。
7. 导出退费表，人员按微信群红包方式自行退费。

### 4.7 月度考勤导出流程

1. 系统读取已发布排班。
2. 合并换班、请假、顶班后的实际值班结果。
3. 汇总每个人的实际值班班次、请假、顶班等记录。
4. 生成月度考勤表。
5. 导出月度考勤表。

### 4.8 微信小程序审批流程

1. 用户在微信小程序查看待办审批或确认事项。
2. 审批人查看申请详情。
3. 审批人同意或拒绝。
4. 系统记录审批意见、审批时间和审批结果。
5. 审批结果同步影响换班、请假或顶班业务状态。

## 5. 业务角色识别

### 5.1 值机员

- 参与排班和值班。
- 查看本人排班。
- 发起换班。
- 对他人换班申请进行同意或拒绝。
- 发起请假申请。
- 查看本人考勤和退费明细。

### 5.2 检修班人员

- 平时上行政班。
- 在值机员请假时可被安排顶班。
- 查看本人顶班记录。
- 参与顶班相关考勤和退费计算。

### 5.3 机房主任

- 可能负责排班管理。
- 安排请假后的顶班人员。
- 可作为顶班人。
- 可能参与或承担领导审批职责。
- 查看本机房排班、请假、换班、顶班、考勤和退费情况。

### 5.4 机房副主任

- 可作为顶班人。
- 可能参与管理或审批。
- 查看与本人或本机房相关的排班、顶班和考勤信息。

### 5.5 领导/审批人

- 审批换班。
- 可能审批请假。
- 通过微信小程序处理审批。
- 查看审批范围内的业务详情。

### 5.6 排班管理员

- 维护排班规则配置（N×M 网格填人选人）。
- 发布和重新发布排班规则。
- 调整个别日期排班。
- 导出值班表。

### 5.7 财务/统计人员

- 查看或导出退费表。
- 查看餐补和法定节假日加班费退费明细。
- 可能导出月度考勤表。

### 5.8 系统管理员

- 管理账号。
- 管理角色和权限。
- 维护系统基础配置。
- 管理台站、班次、规则、节假日和补贴标准。

### 6.2 操作权限

- 发布
- 发起申请
- 同意/拒绝
- 审批

### 6.3 角色权限矩阵

| 角色 | 主要权限 |
| --- | --- |
| 值机员 | 查看本人排班；发起换班；确认换班；发起请假；查看本人考勤和退费明细 |
| 检修班人员 | 查看本人顶班安排；查看本人考勤和退费明细 |
| 机房主任 | 查看本机房数据；安排顶班；可能生成/调整排班；可能审批请假或换班 |
| 机房副主任 | 查看本机房数据；可作为顶班人；可能协助审批或管理 |
| 领导/审批人 | 审批换班；审批请假；查看审批事项详情 |
| 排班管理员 | 维护排班数据；生成、调整、发布排班；导出值班表 |
| 财务/统计人员 | 查看退费结果；导出退费表；导出考勤表 |
| 系统管理员 | 管理账号、角色、权限、台站、班次、规则、节假日、补贴标准 |

### 6.4 数据范围权限

- 值机员只能查看本人相关数据，换班确认时可查看与该申请相关的对方班次信息。
- 机房主任、机房副主任应限制在所属机房或台站范围内。
- 领导/审批人应限制在审批授权范围内。
- 财务/统计人员可查看退费和考勤报表，但是否可查看请假原因等敏感信息需确认。
- 系统管理员可查看和配置全局基础信息。

### 6.5 审批权限

- 换班审批需要至少两类动作：
  - 对方确认
  - 领导审批
- 请假审批是否存在、由谁审批、是否需要多级审批尚未明确。
- 顶班安排是否需要被顶班人确认尚未明确。
- 微信小程序审批应与后台审批权限保持一致。

## 8. 需求缺失和冲突

### 8.1 需求缺失

- 未明确值机员"简单设置"包含哪些字段，例如班组、岗位、可排班状态。
- 未明确排班是否允许人工调整，以及调整权限和记录要求。
- 未明确换班是否只能同岗位/同资质人员之间进行。
- 未明确换班后补贴、退费和考勤按原排班还是实际值班计算。
- 未明确公休假、事假、病假的申请流程、审批人、附件要求和额度规则。
- 未明确法定节假日不得请假的例外场景，例如突发病假。
- 未明确顶班人是否需要账号、是否需要确认、是否可以拒绝。
- 未明确微信小程序支持的功能边界。
- 未明确导出格式，如 Excel、PDF、Word 或打印样式。
- 未明确月度考勤表的统计字段和考勤规则。
- 未明确法定节假日数据来源，是系统维护还是自动同步。
- 未明确餐补退费和加班费退费中"一部分晚班"的时间范围或比例。
- 未明确餐补退费 4 元、节假日加班费退费 56 元是否固定，是否按台站可配置。
- 未明确退费表是否需要按人员汇总、按日期明细，或两者都需要。
- 未明确微信群红包退费后是否需要在系统中登记已退费。
- 未明确历史月份排班和退费数据是否允许修改。
- 未明确账号登录方式、微信绑定方式和权限模型。
- 未明确是否需要消息通知，例如换班待确认、审批待办、排班发布提醒。

### 8.2 潜在冲突或不一致

- 文档说不同台站排班方式不同，但当前又主要适配广播发射台；系统首期范围需要明确，否则排班规则设计复杂度差异很大。
- 排班规则已改为 N 天循环表格方案（见 `docs/design/05-排班规则设计.md`），不再依赖特定台站的算法模式。表格列数和标题由班次定义动态决定，台站差异仅体现在表格填充内容上。
- 法定节假日值机员不得请假，但现实中可能存在病假等不可抗力，需要明确是否完全禁止，还是禁止普通请假但允许特殊审批。
- 需求同时提到换班和请假顶班，两者对实际值班、考勤、退费计算的优先级未明确。
- 餐补和法定节假日加班费按工资发放给晚班值机员，但又要求按实际承担晚班的中班值机员退费；若发生换班或顶班，原工资发放对象与实际值班对象可能不一致，需明确计算口径。
- 顶班人参与退费计算，但顶班人是行政班或管理人员时，其工资中是否已发放餐补/加班费不明确。
- 退费方式为微信群红包，系统只导出退费表；是否需要闭环管理退费状态不明确。

## 9. 需要确认的问题

### 9.1 系统范围

1. 首期只支持广播发射台，还是需要同时支持多个台站和多套排班规则？
同时支持多个台站和多套排班规则。
2. 是否需要维护台站、机房、班组等组织结构？
需要。
3. 是否需要支持多个机房独立排班？
需要。

### 9.2 排班规则

> **⚠ 已重新设计：** 以下 Q&A 为早期需求确认记录，其描述的"晚早组/中班组"排班规则已被 `docs/design/05-排班规则设计.md` 的 N 天循环表格方案替代。保留此 Q&A 仅作为背景参考，不驱动系统实现。

1. 广播发射台完整排班规则是什么？
晚班-早班-晚班-早班，休息两轮。
中班-中班，休息两轮；或者中班-休息一轮。
2. 每个班次固定需要几名值机员？
主城区台站一般是双岗值，2名值机员在岗值班。
3. 示例中同一组人员同日上早班和晚班是否正确？
正确。
4. 自动排班是否需要考虑人员休息时间、连续值班限制、节假日公平性？
轮班制，其他无需考虑。
5. 是否允许排班管理员手工调整自动排班结果？
允许。
6. 排班发布后是否允许修改？修改是否需要审批？
允许管理员修改，无需审批。

### 9.3 人员与账号

1. 值机员、检修班人员、主任、副主任是否都需要系统账号？
需要。
2. 用户是否通过用户名密码登录，还是通过微信登录/绑定？
用户名密码登录和微信登录/绑定都支持。
3. 一个用户是否可能兼任多个角色？
可以。
4. 人员是否需要配置岗位资质，用于限制换班和顶班？
无需配置岗位资质。

### 9.4 换班

是。

可以单向替班。

机房主任审批。
4. 换班审批通过后，考勤和补贴退费是否全部按实际值班人计算？
对。

允许。

允许。

机房主任审批。

无需材料。
3. 法定节假日“不得请假”是否有病假等特殊例外？
无特殊例外。
4. 顶班是否由机房主任直接安排即可，还是需要顶班人确认？
需要顶班人确认。

无资格限制。
6. 顶班是否影响顶班人的正常行政班考勤？
不影响。

### 9.6 补贴与退费

1. 餐补 10/10/14 元是否所有台站通用？
仅限广播发射台。
2. 晚班退给中班的 4 元是否固定可配置？
无需配置。
3. 法定节假日加班费 150 元/人/班是否固定可配置？
无需配置。
4. 晚班退给中班的 56 元如何得出，是否固定可配置？
无需配置。
5. “中班值机员要上一部分晚班”的具体时间段或计算比例是什么？
3小时/8小时，故150*3/8≈56元。系统中无需体现具体时间段和计算。
6. 退费计算遇到换班、请假、顶班时，按原排班、工资发放对象还是实际值班对象计算？
按实际值班对象计算。
7. 顶班人是否已经获得工资中的餐补或节假日加班费？
已获得。
8. 退费表需要明细表、汇总表，还是两者都要？
都要。
9. 系统是否需要记录微信群红包退费是否完成？
无需记录。
