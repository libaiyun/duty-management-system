# 设计修订

本文是 `01-需求分析.md`、`02-原型设计.md`、`03-总体设计.md` 的综合修订，记录多轮讨论后达成的共识。后续开发实施以本文为准。

---

## 1. 核心设计方向

| 决策 | 结论 |
|---|---|
| 部署模式 | 一个实例服务多个机房 |
| 用户归属 | 一人一机房，登录后自动进入所属机房 |
| 简化策略 | 前端按用户所属机房自动筛选，隐藏多机房复杂性 |
| 菜单权限 | 按角色折叠，非本角色可用的菜单不展示 |

## 2. 全局布局

### 顶部栏

```
[系统名称]  [🔔 消息]  [张三 · 发射机房]  [退出]
```

- **普通角色**：机房名称为只读文本，格式"姓名 · 机房名"，不显示台站
- **系统管理员**：同位置显示可点击的机房切换下拉框，切换后所有页面数据范围随之更新
- 全局页面（§4 标注）打开时自动隐藏切换器
- 消息有未读时红点提示

### 样式规范

- 列表页：页面标题 + 操作按钮 → 查询区（高级条件默认折叠） → 表格 → 分页
- 详情：右侧抽屉
- 短流程：居中弹窗
- 状态标签颜色：草稿灰、待处理橙、通过绿、拒绝红、锁定蓝、作废深灰

## 5. 系统管理员特殊规则

- 登录后顶部栏显示机房切换下拉框，必须选中一个机房后才能访问机房相关页面
- 不存在"不选机房看全部"的叠加视图
- 人员管理不提供跨机房全局搜索
- 账号绑定时，人员选择提供全局跨机房搜索下拉框，不要求先切换机房
- 以下页面为全局页面，不依赖机房上下文，打开时隐藏切换器：
  - 台站机房
  - 账号角色
  - 操作日志
  - 备份归档

## 7. 页面设计

### 7.1 排班表

合并原"排班日历页"和"排班明细页"，是系统核心页面。

#### 日历视图（默认）

- 月历网格，每格内按班次分行显示人员
- 行数 = 每格人数 × 本机房班次数
- **本人日期格**浅绿底色高亮
- **法定节假日日期格**浅红底色 + 节假名称
- **已锁定月份**格子置灰不可操作
- 缺岗/异常：人员名后小标签（"已换"、"请假"），点击查看详情

#### 列表视图

- 表格：日期、星期、是否节假日、各班次人员（列标题动态来自 shift_def）、异常标记、操作
- 查询：日期范围、班次、人员、异常类型
- 用于按条件筛选和批量定位

#### 交互

- **值机员**：点击本人高亮格子 → 弹出菜单（"发起换班" / "发起请假"），法定节假日格子"发起请假"置灰
- **主任/管理员**：
  - 点击任意格子 → "编辑人员"弹窗（调整排班）
  - 点击本人格子时，额外显示"换班""请假"选项
- **不在此处发起顶班**：顶班前置条件是请假审批通过，统一走请假记录页

#### 顶部控制

| 控件 | 说明 |
|---|---|
| 月份切换 | 左右箭头翻月，默认本月 |
| 视图切换 | 按钮组 [日历 / 列表] |
| 锁定状态 | 标签：正常 / 已锁定 |
| 导出按钮 | 导出当月 Excel |

---

### 7.2 排班规则

- 打开直接展示本机房规则，无需选择机房
- 首次进入：根据本机房已启用的班次定义，自动生成默认空网格
- 草稿 → 发布流程保留
- 网格按每格人数展开为多行，每行直接选人

示例（每格 2 人，3 班制）：

```
循环日 | 早班(00-08) | 中班(08-16) | 晚班(16-24)
 Day1  | 张三       | 李四       | 王五
       | 赵六       | 钱七       | 孙八
 Day2  | ...        | ...        | ...
```

---

### 7.3 审批中心

待办/已办合一：

- Tab 切换：待办审批 / 已办审批
- 操作在右侧抽屉内完成（同意/拒绝 + 意见）
- 同意请假后自动生成待安排顶班任务

---

### 7.4 请假记录

合并原"顶班安排页"：

- 表格：请假单号、申请人、请假类型、日期、班次、审批状态、顶班状态、操作
- "审批通过 + 待安排顶班"的记录，右侧显示"安排顶班"按钮
- 点击后弹出安排顶班弹窗（选择顶班人 → 发送确认）
- 弹窗内显示顶班人当日排班/顶班情况，用于判断冲突
- 不跳转页面，全流程在请假记录页闭环

---

### 7.5 退费管理

合并原"退费计算页"和"退费明细页"：

- 顶部：月份、退费类型（餐补/节日加班费/全部）、操作按钮（计算/重新计算/复核/锁定/导出）
- 批次状态卡片
- Tab：明细表 / 人员汇总表
- 锁定后禁止重新计算

---

### 7.6 换班申请 / 请假申请

保持个人视角：

- Tab：我发起的 / 待我确认 / 与我相关
- 无论什么角色打开，看到的都是本人相关数据
- 机房级别的换班/请假管理走审批中心和请假记录

---

### 7.7 人员管理

- 机房主任打开自动显示本机房人员
- 系统管理员通过顶部切换器切换机房后查看对应人员
- 无跨机房全局搜索

---

### 7.8 班次规则

- 班次定义表（shift_def）新增 `org_unit_id` 字段，与机房绑定
- 不同机房可有不同班次配置（两班制、三班制等）
- 排班规则的网格列数和标题由本机房启用的班次动态决定

---

### 7.9 节假日与标准

- **节假日**：全局统一维护，无 org_unit_id（各机房共用同一套节假日历）
- **费用标准**：新增 `org_unit_id` 字段，按机房粒度维护
- 首次进入某机房时预填充默认值：早班餐补 10 元、中班餐补 10 元、晚班餐补 14 元、餐补退费 4 元、节假日加班费 150 元/人/班、加班费退费 56 元

## 8. 状态流转（不变）

### 排班规则

`草稿 ↔ 已发布`

### 换班

`草稿 → 待对方确认 → 待主任审批 → 已通过 → 已生效`
`待对方确认 → 对方拒绝`
`待主任审批 → 审批拒绝`
`草稿 / 待对方确认 / 待主任审批 → 已撤回`
`已通过 / 已生效 → 已作废`

### 请假

`草稿 → 待主任审批 → 已通过 → 待安排顶班 → 待顶班确认 → 已完成`
`待主任审批 → 审批拒绝`
`草稿 / 待主任审批 → 已撤回`

### 顶班

`待安排 → 待顶班人确认 → 已确认 → 已生效`
`待顶班人确认 → 顶班人拒绝 → 待重新安排`
`已生效 → 已作废`

### 退费批次

`未计算 → 已计算 → 已复核 → 已锁定 → 已导出`
`已计算 / 已复核 → 重新计算`
